Easing

Fonctions de lissage — calculer manuellement des valeurs interpolées avec des courbes (utile si vous n'utilisez pas Tween).

Global automatique

API

FonctionDescription
Easing.apply(nom, t)Applique la courbe au paramètre t (0.0 à 1.0). Retourne une valeur entre 0 et 1.
Easing.lerp(a, b, t, nom)Interpolation de a vers b avec la courbe nommée.

Nom de courbeEffet
"linear"Vitesse constante.
"easeIn"Démarre lentement, accélère.
"easeOut"Démarre vite, ralentit.
"easeInOut"Lent au début et à la fin.
"easeInBack"Recule légèrement avant de partir.
"easeOutBack"Dépasse légèrement avant de s'arrêter.
"easeOutBounce"Rebondit à l'arrivée.
"easeOutElastic"Vibre comme un élastique.
Conseil : dans la plupart des cas, utilisez Tween plutôt qu'Easing. Easing est utile quand vous calculez manuellement une animation dans OnUpdate.

Exemple

lua  ·  Animation manuelle dans OnUpdate
-- Faire apparaître un panneau avec un effet rebond
local duree      = 0.6   -- secondes
local temps      = 0
local debut_y    = -200  -- hors écran (au-dessus)
local arrivee_y  = 50    -- position finale

function OnUpdate(entity, dt)
    if temps < duree then
        temps = temps + dt
        local t = math.min(temps / duree, 1.0)

        -- Appliquer la courbe bounce
        local t_lisse = Easing.apply("easeOutBounce", t)

        local y = Easing.lerp(debut_y, arrivee_y, t, "easeOutBounce")
        World.setPosition(entity, 400, y)
    end
end
