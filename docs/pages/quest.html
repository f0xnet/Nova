Quest

Système de quêtes à étapes — enregistrer une quête, la démarrer, avancer stage par stage, la terminer ou la rater.

Global automatique

API

FonctionDescription
Quest.register(id, def)Déclare une quête avec ses étapes. À appeler une seule fois (démarrage).
Quest.start(id)Démarre la quête. Retourne false si déjà commencée.
Quest.advance(id)Passe à l'étape suivante. Retourne false si déjà à la dernière.
Quest.complete(id)Marque la quête comme terminée (réussie).
Quest.fail(id)Marque la quête comme échouée.
Quest.isActive(id)Vrai si la quête est en cours.
Quest.isCompleted(id)Vrai si la quête est terminée avec succès.
Quest.getStage(id)Retourne l'étape actuelle (table avec les données définies).
Quest.getStageIndex(id)Index de l'étape actuelle (commence à 1).
Quest.getName(id)Nom lisible de la quête.
Quest.getAll()Liste de tous les ids de quêtes enregistrées.
Flux : Quest.register() au démarrage → Quest.start() quand donnée → Quest.advance() à chaque objectif → Quest.complete() à la fin. Les événements "quest_complete" et "quest_fail" sont émis automatiquement sur l'EventBus.

Exemples

lua  ·  Quête avec plusieurs étapes
-- Définir la quête au démarrage
Quest.register("delivrance_village", {
    name   = "Délivrance du village",
    stages = {
        { desc = "Trouver le chef de village." },
        { desc = "Vaincre les 5 gobelins qui pillent." },
        { desc = "Retourner voir le chef." },
    }
})

-- Étape 1 : parler au chef
function OnActivate(activatorId, actionID)
    if not Quest.isActive("delivrance_village") then
        Quest.start("delivrance_village")
        Notify.show("Nouvelle quête : " .. Quest.getName("delivrance_village"))
    end
end

-- Étape 2 : tuer les gobelins (dans le script gobelin)
local gobelins_tues = 0

function OnStatZeroed(entityId, stat)
    if stat == "Vie" and Quest.isActive("delivrance_village")
        and Quest.getStageIndex("delivrance_village") == 2 then
        gobelins_tues = gobelins_tues + 1
        Notify.show("Gobelins : " .. gobelins_tues .. " / 5")

        if gobelins_tues >= 5 then
            Quest.advance("delivrance_village")  -- passer à l'étape 3
        end
    end
end

-- Étape 3 : retourner au chef (dans son script)
function OnActivate(activatorId, actionID)
    if Quest.isActive("delivrance_village") and Quest.getStageIndex("delivrance_village") == 3 then
        Quest.complete("delivrance_village")
    end
end

lua  ·  Réagir à la completion
-- Écouter les événements de quête
EventBus.on("quest_complete", function(data)
    if data.id == "delivrance_village" then
        Inventory.add(joueur.id, "piece_or", 100)
        Notify.show("Quête terminée ! +100 pièces d'or.",  { color = "lime" })
        Flag.set("village_sauve")
    end
end)

EventBus.on("quest_fail", function(data)
    Notify.show("Échec : " .. Quest.getName(data.id),  { color = "red" })
end)
