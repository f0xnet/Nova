Achievement

Succès et trophées — définir, débloquer, afficher, persister entre les sessions.

Global automatique

API

FonctionDescription
Achievement.define(id, opts)Déclare un succès. À appeler une seule fois (démarrage).
Achievement.unlock(id)Débloque le succès. Ne fait rien si déjà débloqué. Émet "achievement_unlocked".
Achievement.isUnlocked(id)Vrai si le succès a déjà été obtenu.
Achievement.getAll()Retourne { [id] = { name, desc, hidden, unlocked, unlockedAt } }.
Achievement.getUnlocked()Liste triée des ids débloqués.
Achievement.save()Sauvegarde l'état dans Persist.
Achievement.load()Recharge l'état depuis Persist.
Achievement.reset()Réinitialise tous les succès (tests uniquement).

Option de define()Description
nameNom affiché au joueur.
descDescription du succès.
hiddenSi true, le succès est caché jusqu'à ce qu'il soit débloqué.
condFonction optionnelle (ctx) → bool — condition externe vérifiable.

Événements émis

EventBus

achievement_unlocked{ id, name }

Exemples

lua  ·  Définir et débloquer des succès
-- Définir au démarrage (script global)
Achievement.define("premier_pas", {
    name = "Premiers pas",
    desc = "Lancer le jeu pour la première fois.",
})

Achievement.define("tueur_de_dragon", {
    name = "Tueur de dragon",
    desc = "Vaincre le boss final.",
})

Achievement.define("collectionneur", {
    name = "Collectionneur",
    desc = "Remplir complètement votre inventaire.",
})

Achievement.define("salle_secrete", {
    name   = "???",
    desc   = "Vous avez trouvé la salle cachée.",
    hidden = true,  -- titre et description masqués avant déblocage
})

-- Charger l'état sauvegardé au démarrage
Achievement.load()

-- Débloquer
Achievement.unlock("premier_pas")

-- À la mort du boss (dans le script du boss)
function OnStatZeroed(entityId, stat)
    if stat == "Vie" then
        Achievement.unlock("tueur_de_dragon")
        Achievement.save()
    end
end

lua  ·  Réagir au déblocage (affichage)
-- Brancher une notification sur l'EventBus
EventBus.on("achievement_unlocked", function(data)
    Notify.show("🏆 Succès débloqué : " .. data.name, {
        color    = "gold",
        duration = 5.0,
        size     = 1.2,
    })
    Sound.play("data/sounds/achievement.ogg")
end)

lua  ·  Succès conditionnel et écran des trophées
-- Succès "finir sans mourir"
EventBus.on("joueur_mort", function()
    Flag.set("mort_au_moins_une_fois")
end)

EventBus.on("fin_du_jeu", function()
    if not Flag.get("mort_au_moins_une_fois") then
        Achievement.unlock("sans_mourir")
    end
    Achievement.save()
end)

-- Afficher l'écran des trophées
function afficherSucces()
    local tous = Achievement.getAll()
    for id, data in pairs(tous) do
        if not data.hidden or data.unlocked then
            local statut = data.unlocked and "✓" or "○"
            print(statut .. " " .. data.name .. " — " .. data.desc)
        end
    end
end
