EntityState

Persistance de l'état des entités pré-placées dans la scène — un ennemi tué reste mort, un coffre ouvert reste ouvert, même après un redémarrage.

Global automatique
Comment ça marche : quand vous appelez EntityState.disable(entity), l'état "mort" est sauvegardé automatiquement via Persist. Au prochain chargement de la scène, l'entité sera désactivée immédiatement lors de son init.

Convention : stateID dans le JSON de scène

Chaque entité devant persister son état doit avoir un identifiant unique. Ajoutez-le dans le JSON de scène :


json  ·  data/scenes/donjon.scene
-- Dans le JSON, l'entité a une propriété stateID :
-- {
--   "type": "goblin",
--   "x": 400, "y": 300,
--   "properties": {
--     "stateID": "donjon_01_goblin_A",
--     "vie": 30
--   }
-- }

API

FonctionDescription
EntityState.register(entity, stateID)Enregistre l'entité. Si elle était morte, la désactive immédiatement. À appeler dans init.
EntityState.disable(entity)Désactive l'entité ET sauvegarde l'état "mort" sur disque.
EntityState.enable(entity)Réactive l'entité ET efface l'état sauvegardé.
EntityState.isDead(stateID)Vrai si cet ID est marqué comme "mort" en sauvegarde.
EntityState.reset(stateID)Efface la sauvegarde d'un état (ne touche pas l'entité en mémoire).
EntityState.resetAll()Efface TOUS les états sauvegardés — à utiliser pour une nouvelle partie.

Exemple complet — Ennemi persistant

lua  ·  scripts/ennemi.lua
local vie      = 30
local monStateID = ""

function init(entity)
    -- 1. Calculer un ID unique (depuis le JSON ou depuis l'entity.id)
    monStateID = self.stateID or ("ennemi_" .. tostring(entity.id))

    -- 2. Enregistrer : si cet ennemi a déjà été tué, il sera
    --    automatiquement désactivé ICI. Pas besoin de vérifier manuellement.
    EntityState.register(entity, monStateID)

    -- 3. Initialiser les stats normalement
    vie = self.vie or 30
    Anim.play(entity, "idle", true)
end

function mourir(entity)
    Sound.play("data/sounds/mort.ogg")
    Particles.emit(World.getPosition(entity).x, World.getPosition(entity).y, {
        count = 15, speed = 120, lifetime = 0.5
    })

    -- EntityState.disable() = entity:disable() + sauvegarde "mort"
    EntityState.disable(entity)

    -- Loot
    Loot.dropFor(entity, "goblin")
end

function OnMessage(msg, data)
    if msg == "takeDamage" then
        vie = vie - data.amount
        if vie <= 0 then mourir(entity) end
    end
end

Nouvelle partie

lua
-- Réinitialiser tout pour une nouvelle partie
function nouvellePartie()
    EntityState.resetAll()   -- tous les ennemis revivent
    Persist.clear()          -- effacer la sauvegarde
    Flag.clearAll()          -- remettre les flags à zéro
    Scene.transition("scene_intro")
end
