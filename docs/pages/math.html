Math, Vec2 & Color

Fonctions mathématiques, vecteurs 2D et type couleur RGBA.

⚠️ Toujours utiliser Color.new(...), jamais Color(...).
Le call direct Color(r, g, b, a) est exposé par le binding C++ (sol2) mais échoue silencieusement dans certains contextes — notamment quand la couleur est créée au chargement d'un module require'é et utilisée plus tard dans un callback de rendu. Le module charge sans erreur mais la valeur stockée est invalide, provoquant des crashes Lua silencieux à l'usage.

Toujours préférer Color.new(...) qui passe par l'extension Lua de nova/color_ext.lua et fonctionne dans tous les contextes. Tous les modules nova et tous les exemples de cette doc respectent cette convention.

lua  ·  Mouvement fluide vers une cible
-- Approcher une valeur de vitesse progressivement (accélération)
local vitesse_actuelle = 0
local vitesse_max      = 200

function update(entity, dt)
    -- Math.approach avance de (acceleration * dt) sans dépasser vitesse_max
    vitesse_actuelle = Math.approach(vitesse_actuelle, vitesse_max, 300 * dt)

    local pos = entity:getPosition()
    entity:setPosition(pos.x + vitesse_actuelle * dt, pos.y)
end

lua  ·  Direction et déplacement avec Vec2
-- Calculer la direction normalisée vers une cible
local pos_a = archer:getPosition()
local pos_b = cible:getPosition()

local direction = Vec2.normalize(Vec2.new(
    pos_b.x - pos_a.x,
    pos_b.y - pos_a.y
))

-- Déplacer l'entité dans cette direction
local VITESSE = 150
archer:setPosition(
    pos_a.x + direction.x * VITESSE * dt,
    pos_a.y + direction.y * VITESSE * dt
)
