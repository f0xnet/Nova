Trigger

Zones invisibles qui déclenchent des actions quand une entité entre, sort, ou reste dedans.

Global automatiqueÉmet des événements

API

FonctionDescription
Trigger.create(id, rect, opts)Crée une zone. rect = {x, y, w, h} en pixels.
Trigger.remove(id)Supprime la zone.
Trigger.enable(id) / disable(id)Active ou désactive la zone sans la supprimer.
Trigger.clear()Supprime toutes les zones.

Option (opts)Description
onEnter = function(entityId)Appelée quand une entité entre dans la zone.
onExit = function(entityId)Appelée quand une entité sort de la zone.
onStay = function(entityId, dt)Appelée chaque frame tant qu'une entité est dans la zone.
tags = {"player"}Ne déclencher que pour les entités avec ce tag.
once = trueSe désactive automatiquement après le premier déclenchement.

Exemples

lua  ·  Zone de lave
-- Zone qui brûle le joueur tant qu'il est dedans
Trigger.create("lave_01", { x = 400, y = 500, w = 200, h = 60 }, {
    tags    = { "player" },
    onEnter = function(eid)
        Sound.play("data/sounds/feu.ogg")
        SceneFX.flash(Color.new(255, 80, 0, 120), 0.3)
    end,
    onStay  = function(eid, dt)
        Stats.mod(eid, "Vie", -25 * dt)  -- 25 dégâts par seconde
        Notify.floatingText(Registry:getEntity(eid), "🔥", { color = "orange" })
    end,
    onExit  = function(eid)
        Sound.stop("data/sounds/feu.ogg")
    end,
})

lua  ·  Déclencheur de boss (une seule fois)
-- Le boss apparaît quand le joueur entre dans la salle
Trigger.create("entree_boss", { x = 800, y = 100, w = 64, h = 200 }, {
    tags    = { "player" },
    once    = true,   -- une seule fois !
    onEnter = function()
        -- Fermer la porte derrière le joueur
        EventBus.emit("porte_boss_fermee", {})
        -- Lancer la cinématique du boss
        Scheduler.start(function()
            Sound.fadeMusic(0, 0.5, function()
                Sound.playMusic("data/music/boss.ogg")
                Sound.fadeMusic(1, 1.0)
            end)
            Scheduler.wait(0.5)
            EventBus.emit("boss_combat_commence", {})
        end)
    end,
})

lua  ·  Zone de sauvegarde
-- Sauvegarder la progression quand le joueur touche un cristal
Trigger.create("cristal_save", { x = 512, y = 256, w = 32, h = 32 }, {
    tags    = { "player" },
    once    = true,
    onEnter = function()
        local pos = World.findByTag("player"):getPosition()
        Persist.set("checkpoint_x", pos.x)
        Persist.set("checkpoint_y", pos.y)
        Persist.set("dernier_checkpoint", "salle_cristal")
        Notify.show("✓ Progression sauvegardée", { color = "cyan", duration = 3 })
        Sound.play("data/sounds/save.ogg")
    end,
})

Événements émis

EventBus

trigger_enter{ id, entityId }
trigger_exit{ id, entityId }
