Achievement

Succès et trophées — débloquer des succès, afficher des notifications, vérifier si déjà obtenus.

Global automatique

API

FonctionDescription
Achievement.unlock(id)Débloque le succès. Ne fait rien si déjà débloqué. Affiche une notification automatiquement.
Achievement.isUnlocked(id)Vrai si le succès a déjà été obtenu.
Achievement.setProgress(id, valeur)Met à jour la progression d'un succès numérique.
Achievement.getProgress(id)Progression actuelle.
Achievement.getGoal(id)Valeur cible (définie dans la config).
Configuration : les succès sont définis dans data/achievements.json. Chaque succès a un id, un nom, une description et une icône.

Exemples

lua  ·  Succès simples
-- Débloquer un succès d'un coup
Achievement.unlock("premier_pas")       -- "Faire ses premiers pas"
Achievement.unlock("tuer_boss")         -- "Vaincre le boss final"

-- Vérifier avant de donner une récompense unique
if not Achievement.isUnlocked("collectionneur") then
    Achievement.unlock("collectionneur")
    Inventory.give(joueur, "titre_collectionneur")
end

lua  ·  Succès progressif "Tuer 100 ennemis"
-- Dans le script ennemi, à sa mort
function OnDestroy(entity)
    -- Incrémenter le compteur global
    local tues = Achievement.getProgress("tueur") + 1
    Achievement.setProgress("tueur", tues)

    -- Débloquer automatiquement quand l'objectif est atteint
    if tues >= Achievement.getGoal("tueur") then
        Achievement.unlock("tueur")
        -- "tueur" → "Tuer 100 ennemis" → notification + trophée
    end
end

lua  ·  Succès secrets et conditions spéciales
-- Finir le jeu sans mourir
EventBus.on("joueur_mort", function()
    Flag.set("est_mort_une_fois")
end)

EventBus.on("fin_du_jeu", function()
    if not Flag.get("est_mort_une_fois") then
        Achievement.unlock("sans_mourir")
    end
end)

-- Trouver tous les secrets d'une zone
local secrets_trouves = 0
local total_secrets   = 5

EventBus.on("secret_trouve", function()
    secrets_trouves = secrets_trouves + 1
    if secrets_trouves >= total_secrets then
        Achievement.unlock("explorateur")
    end
end)
