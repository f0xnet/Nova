Guide de démarrage rapide

De zéro à un script fonctionnel en quelques minutes — les bases essentielles pour scripter dans Nova.

1. Le squelette d'un script

Chaque script attache deux fonctions à une entité. Nova les appelle automatiquement :

lua  ·  structure minimale
-- init est appelé une seule fois quand l'entité est créée.
-- 'entity' est l'entité propriétaire du script (global injecté).
function init(entity)
    Log.info("Entité prête : " .. tostring(entity.id))
end

-- update est appelé à chaque frame.
-- dt = temps écoulé depuis la dernière frame (en secondes).
function update(entity, dt)
    -- logique frame par frame ici
end
Globals automatiques : entity, self (propriétés JSON de la scène), et tous les modules Nova (Stats, Anim, Timer…) sont disponibles sans require.

2. Lire les propriétés de la scène

Les propriétés définies dans l'éditeur de scène sont accessibles via self :

lua  ·  propriétés JSON → self
-- Dans l'éditeur, l'entité a les propriétés : { "vie": 80, "vitesse": 120 }
function init(entity)
    local vie     = self.vie     or 100
    local vitesse = self.vitesse or 80

    Stats.init(entity.id, {
        Vie    = vie,
        VieMax = vie,
    })
end

3. Réagir à des événements

Nova déclenche des fonctions nommées sur votre script en réponse à des événements moteur :

lua  ·  handlers nommés
-- Appelé quand une stat de CETTE entité atteint zéro.
function OnStatZeroed(entityId, stat)
    if stat == "Vie" then
        Anim.play(entity, "death", false)
        Sound.play("data/sounds/mort.ogg")
        Timer.after(1.0, function()
            entity:disable()
        end)
    end
end

-- Appelé quand une entité entre dans la zone de trigger.
-- triggerId = nom (string) de la zone ; entityId = id numérique de l'entrant.
function OnTriggerEnter(triggerId, entityId)
    local joueur = World.findByTag("player")
    if joueur and entityId == joueur.id then
        Notify.show("Zone atteinte !", { color = "lime" })
    end
end

-- Appelé quand le script reçoit un message via EventBus.
function OnMessage(msg, data)
    if msg == "alerte" then
        Log.info("Message reçu : " .. msg)
    end
end

4. Utiliser les modules courants

lua  ·  modules essentiels
function init(entity)
    -- Initialiser les stats depuis les propriétés de scène
    Stats.init(entity.id, { Vie = self.vie or 100, VieMax = self.vie or 100 })

    -- Jouer l'animation idle en boucle
    Anim.play(entity, "idle", true)

    -- Pré-charger les sons pour éviter la latence
    Sound.preload("data/sounds/attaque.ogg")
end

function update(entity, dt)
    local joueur = World.findByTag("player")
    if not joueur then return end

    -- Poursuivre le joueur s'il est proche
    if entity:getDistance(joueur) < 300 then
        Nav.moveTo(entity, joueur, 120)
        Anim.play(entity, "run", true)
    else
        Nav.stop(entity)
        Anim.play(entity, "idle", true)
    end
end

5. Script complet — ennemi simple

Ce script combine tout ce qui précède : initialisation, poursuite, attaque et mort.

lua  ·  ennemi_simple.lua
local VITESSE    = 120
local DIST_AGGRO = 300
local DIST_ATK   = 60
local DMG        = 15
local cd_attaque = Cooldown.new(1.2)

function init(entity)
    local pv = self.vie or 60
    Stats.init(entity.id, { Vie = pv, VieMax = pv })
    Anim.play(entity, "idle", true)
end

function update(entity, dt)
    local joueur = World.findByTag("player")
    if not joueur then return end

    local dist = entity:getDistance(joueur)

    if dist < DIST_ATK then
        -- Attaque au corps à corps
        Nav.stop(entity)
        Anim.play(entity, "attack", false)
        if Cooldown.ready(cd_attaque) then
            Stats.mod(joueur.id, "Vie", -DMG)
            Camera.shake(0.2, 6)
            Cooldown.reset(cd_attaque)
        end
    elseif dist < DIST_AGGRO then
        -- Poursuite
        Nav.moveTo(entity, joueur, VITESSE)
        Anim.play(entity, "run", true)
    else
        Nav.stop(entity)
        Anim.play(entity, "idle", true)
    end
end

function OnStatZeroed(entityId, stat)
    if stat == "Vie" then
        Nav.stop(entity)
        Anim.play(entity, "death", false)
        Sound.play("data/sounds/ennemi_mort.ogg")

        local joueur = World.findByTag("player")
        if joueur then
            Loot.dropFor(joueur, "gobelin")
        end

        Timer.after(1.5, function()
            entity:disable()
        end)
    end
end
