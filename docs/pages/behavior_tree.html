BT — Behavior Trees

Arbres de comportement pour l'IA des entités. Composez des arbres à partir de nœuds Sequence, Selector, Parallel, Action et Condition.

Global automatique

Statuts

ConstanteValeurSignification
BT.SUCCESS1L'action ou condition s'est terminée avec succès.
BT.FAILURE0L'action a échoué.
BT.RUNNING2L'action est en cours — sera rappelée au prochain frame.

Nœuds feuilles

FonctionDescription
BT.action(fn)Enveloppe une fonction d'action. fn(entity, dt) doit retourner SUCCESS, FAILURE ou RUNNING.
BT.condition(fn)Enveloppe une fonction booléenne. Retourne SUCCESS si fn(entity, dt) est truthy, FAILURE sinon.

Nœuds composites

FonctionDescription
BT.sequence(...)Exécute les enfants dans l'ordre. S'arrête au premier FAILURE ou RUNNING. Retourne SUCCESS uniquement si tous réussissent. (AND logique)
BT.selector(...)Exécute les enfants dans l'ordre. S'arrête au premier SUCCESS ou RUNNING. Retourne FAILURE uniquement si tous échouent. (OR logique)
BT.parallel(...)Exécute tous les enfants chaque tick. Retourne FAILURE si l'un échoue, RUNNING si l'un est en cours, SUCCESS sinon.

Décorateurs

FonctionDescription
BT.invert(child)Inverse SUCCESS et FAILURE. RUNNING est transmis sans modification.
BT.succeed(child)Toujours SUCCESS, quel que soit le résultat de l'enfant.
BT.fail(child)Toujours FAILURE, quel que soit le résultat de l'enfant.
BT.loop(child, n)Répète l'enfant n fois. n = -1 = boucle infinie. Retourne RUNNING pendant la répétition, SUCCESS quand le compteur est atteint, FAILURE si l'enfant échoue.

Exécution

FonctionDescription
BT.run(tree, entity, dt)Exécute l'arbre pour entity. Retourne le statut de la racine. À appeler dans update(entity, dt).
Stateless par défaut : les nœuds BT ne maintiennent pas d'état interne par entité. Sequence et Selector repartent du début à chaque tick. Les actions multi-frame (déplacement, animation) maintiennent leur propre état dans l'entité ou via StateMachine. BT.loop est l'exception — il utilise une closure, donc créez l'arbre dans init() et non comme constante de module.

Exemples

lua  ·  IA de patrouille avec détection du joueur
local tree

function init(entity)
    tree = BT.selector(
        -- Priorité 1 : si on voit le joueur, le poursuivre
        BT.sequence(
            BT.condition(function(e)
                local joueur = Game.getPlayer()
                if not joueur then return false end
                return Physics.distance(e, joueur) < 200
            end),
            BT.action(function(e, dt)
                return chase(e, dt)   -- retourne RUNNING tant que pas arrivé
            end)
        ),
        -- Priorité 2 : sinon, patrouiller
        BT.action(function(e, dt)
            return patrol(e, dt)
        end)
    )
end

function update(entity, dt)
    BT.run(tree, entity, dt)
end

lua  ·  Comportement de boss multi-phases
local tree

function init(entity)
    tree = BT.selector(
        -- Phase rage : vie < 30%
        BT.sequence(
            BT.condition(function(e)
                local hp    = Stats.get(e.id, "Vie", 0)
                local hpMax = Stats.get(e.id, "VieMax", 1)
                return hp / hpMax < 0.3
            end),
            BT.action(function(e, dt) return attaqueRage(e, dt) end)
        ),
        -- Phase normale : attaque + défense en parallèle
        BT.parallel(
            BT.action(function(e, dt) return attaqueNormale(e, dt) end),
            BT.action(function(e, dt) return regenerer(e, dt) end)
        )
    )
end

function update(entity, dt)
    BT.run(tree, entity, dt)
end

lua  ·  Décorateurs — patrouille en boucle 3 fois
local tree

function init(entity)
    tree = BT.sequence(
        -- Inverser la condition : continuer si PAS de joueur visible
        BT.invert(
            BT.condition(function(e)
                return Physics.distance(e, Game.getPlayer()) < 150
            end)
        ),
        -- Boucler 3 fois sur le waypoint suivant
        BT.loop(
            BT.action(function(e, dt) return allerAuWaypointSuivant(e, dt) end),
            3
        )
    )
end
