I18n

Internationalisation — afficher les textes dans la langue du joueur grâce à des fichiers de traduction.

Global automatique

API

FonctionDescription
I18n.load(langue, chemin)Charge un fichier de traduction pour une langue donnée.
I18n.loadTable(langue, table)Charge les traductions depuis une table Lua directement.
I18n.set(code)Change la langue active. Ex : "fr", "en", "de".
I18n.get()Retourne le code de la langue active.
I18n.t(cle, ...)Retourne la traduction de la clé. Retourne la clé si non trouvée.
I18n.has(cle)Vrai si la clé existe dans la langue active.
I18n.fallback(code)Langue de repli si une clé est manquante.

Fichiers de traduction

Placez vos fichiers dans data/i18n/. Un module Lua par langue, chargé manuellement au démarrage :

lua  ·  data/i18n/fr.lua
return {
    ["menu.jouer"]        = "Jouer",
    ["menu.quitter"]      = "Quitter",
    ["hud.vie"]           = "Vie",
    ["notif.niveau"]      = "Niveau %d atteint !",
    ["notif.objet"]       = "Obtenu : %s",
    ["dialogue.marchand"] = "Bonjour, aventurier !",
}

Exemples

lua  ·  Charger et utiliser les traductions
-- Charger au démarrage (script global)
I18n.load("fr", "data/i18n/fr")
I18n.load("en", "data/i18n/en")
I18n.fallback("en")   -- si une clé manque en fr, utiliser en

-- Restaurer la langue de la dernière session
local langue = Persist.get("langue", "fr")
I18n.set(langue)

-- Texte simple
local texte_jouer = I18n.t("menu.jouer")   -- "Jouer" ou "Play"

-- Texte avec arguments (string.format : %d, %s, %f…)
local notif = I18n.t("notif.niveau", 5)
Notify.show(notif,  { color = "lime" })   -- "Niveau 5 atteint !"

local objet = I18n.t("notif.objet", "Épée longue")
Notify.show(objet)   -- "Obtenu : Épée longue"

lua  ·  Changer la langue depuis les options
function changerLangue(code)
    I18n.set(code)
    Persist.set("langue", code)
    Notify.show("Langue : " .. code)
end

-- Appeler depuis le menu options
changerLangue("en")
