Timer

Exécuter du code après un délai ou à intervalles réguliers — sans bloquer le jeu.

Global automatique
Pourquoi Timer plutôt que wait() ? Le jeu continue de tourner pendant le délai. Un Timer.after(2, fn) attend 2 secondes puis appelle fn, sans figer le jeu.
Nettoyage automatique : chaque timer est lié à une scène. Si aucun scope n'est fourni, Scene.current() est utilisé automatiquement. Au changement de scène, tous les timers de la scène sortante sont annulés — impossible de créer un timer qui fuit entre scènes.

API

FonctionDescriptionRetour
Timer.after(secondes, fonction, scope)Appelle fonction() une seule fois après le délai. scope optionnel — défaut : Scene.current().id
Timer.every(intervalle, fonction, scope)Appelle fonction() en boucle toutes les N secondes. scope optionnel — défaut : Scene.current().id
Timer.cancel(id)Annule un timer avant qu'il ne se déclenche.—
Timer.cancelScope(scope)Annule tous les timers d'un scope donné (ex : nom de scène, ou tostring(entity.id)).—
Timer.cancelAll()Annule tous les timers actifs (reset global — rarement nécessaire).—

Exemples

lua
-- Faire apparaître une explosion 2 secondes après
Timer.after(2.0, function()
    Particles.emit(x, y, { count = 30, speed = 200 })
    Sound.play("data/sounds/boom.ogg")
    Camera.shake(0.5, 15)
end)

-- Régénérer 5 PV toutes les 3 secondes
local timerRegen = Timer.every(3.0, function()
    local vie    = Stats.get(joueur.id, "Vie", 0)
    local vieMax = Stats.get(joueur.id, "VieMax", 100)
    if vie < vieMax then
        Stats.mod(joueur.id, "Vie", 5)
        Notify.floatingText(joueur, "+5 PV", { color = "green" })
    end
end)

-- Arrêter la régénération quand le joueur entre en combat
EventBus.on("combat_commence", function()
    Timer.cancel(timerRegen)
end)

-- Fermer une porte automatiquement après 5 secondes
function ouvrirPorte(porte)
    Anim.play(porte, "open", false)
    Sound.play("data/sounds/porte.ogg")

    Timer.after(5.0, function()
        Anim.play(porte, "close", false)
    end)
end

-- Scope explicite sur une entité (timer lié au cycle de vie de l'entité)
function init(entity)
    Timer.every(3.0, function()
        Stats.mod(entity.id, "Vie", 5)   -- régénération périodique
    end, tostring(entity.id))
end
