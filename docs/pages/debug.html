Debug

Dessiner des formes et afficher des valeurs à l'écran pour déboguer votre jeu. Mettre Debug.enabled = false en production.

Global automatique
Production : pensez à désactiver le debug avec Debug.enabled = false dans votre script de jeu principal avant de livrer.

API

FonctionDescription
Debug.enabledVariable booléenne. Mettre à false pour tout désactiver.
Debug.drawRect(x,y,w,h,color,duree)Rectangle en fil de fer. duree=0 = 1 seul frame.
Debug.fillRect(x,y,w,h,color,duree)Rectangle rempli.
Debug.drawLine(x1,y1,x2,y2,color,duree,epaisseur)Ligne. epaisseur en pixels (défaut 1).
Debug.drawCircle(x,y,r,color,duree,segments)Cercle (approximé par polygone). segments optionnel, défaut 16.
Debug.label(x,y,texte,color,duree)Texte à une position.
Debug.watch(cle,valeur)Affiche cle = valeur en coin d'écran jusqu'au prochain frame.
Debug.clear()Efface toutes les commandes en attente et les watches.

Exemples

lua  ·  Visualiser les zones de collision et d'attaque
function update(entity, dt)
    local pos = World.getPosition(entity)

    -- Zone d'attaque (cercle rouge)
    Debug.drawCircle(pos.x, pos.y, 80, Color.new(255, 0, 0, 80), 0)

    -- Zone de détection (cercle jaune)
    Debug.drawCircle(pos.x, pos.y, 200, Color.new(255, 220, 0, 40), 0)

    -- Valeurs en temps réel
    Debug.watch("vie",      Stats.get(entity.id, "Vie", 0))
    Debug.watch("état",     sm:getState())
    Debug.watch("vitesse",  string.format("%.1f", vitesseActuelle))
    Debug.watch("fps",      math.floor(1/dt))
end

lua  ·  Tracer un chemin Nav
-- Afficher le chemin calculé par Nav
local chemin = Nav.findPath(entity, joueur)
for i = 1, #chemin - 1 do
    Debug.drawLine(
        chemin[i].x,   chemin[i].y,
        chemin[i+1].x, chemin[i+1].y,
        Color.new(0, 200, 255), 0
    )
end

-- Point de destination
if #chemin > 0 then
    local dest = chemin[#chemin]
    Debug.drawCircle(dest.x, dest.y, 6, Color.new(0, 255, 0), 0)
end
