Nav

Déplacer une entité automatiquement vers une cible en contournant les obstacles — pathfinding via le graphe de waypoints de la scène.

Global automatique

API

FonctionDescription
Nav.moveTo(entity, cible, vitesse, onArrivee)Navigation automatique vers la cible. cible peut être une entité ou {x, y}. onArrivee() est appelé quand l'entité arrive.
Nav.findPath(entity, cible)Calcule le chemin sans se déplacer. Retourne [{x,y}...].
Nav.moveAlongPath(entity, chemin, vitesse, onArrivee)Suit un chemin pré-calculé.
Nav.stop(entity)Arrête le déplacement en cours.
Nav.isMoving(entity)Vrai si l'entité est en cours de déplacement.

Exemple — PNJ qui patrouille

lua
-- Un garde qui fait des allers-retours entre deux points
local pointA   = { x = 200, y = 400 }
local pointB   = { x = 600, y = 400 }
local versPointB = true  -- direction actuelle

local function patrouiller(entity)
    local cible = versPointB and pointB or pointA

    Nav.moveTo(entity, cible, 70, function()
        -- Arrivé ! Petite pause, puis on repart dans l'autre sens
        versPointB = not versPointB
        Anim.play(entity, "idle", true)

        Timer.after(1.5, function()
            patrouiller(entity)
        end)
    end)

    Anim.play(entity, "walk", true)
end

function OnInit(entity, props)
    patrouiller(entity)
end

Exemple — Ennemi qui poursuit le joueur

lua
function OnUpdate(entity, dt)
    local joueur = World.findByTag("player")
    if not joueur then return end

    local dist = World.distance(entity, joueur)

    if dist < 200 then
        -- Le joueur est détecté : le suivre en contournant les murs
        Nav.moveTo(entity, joueur, 100)
        Anim.play(entity, "run", true)
    elseif dist > 300 then
        -- Trop loin : s'arrêter
        Nav.stop(entity)
        Anim.play(entity, "idle", true)
    end
end
