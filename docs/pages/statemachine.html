StateMachine

Machine à états — organiser le comportement d'un ennemi ou d'un objet en états distincts (Patrouille, Poursuite, Attaque, Mort…).

Global automatique

API

FonctionDescription
StateMachine.new(etats, etat_initial)Crée une nouvelle machine à états. Retourne un objet sm.
sm:update(dt)À appeler dans OnUpdate — exécute l'état actuel.
sm:setState(nom)Change d'état immédiatement. Appelle onExit de l'ancien puis onEnter du nouveau.
sm:getState()Nom de l'état actuel.
sm:is(nom)Vrai si l'état actuel est nom.

Structure d'un état

Chaque état est une table avec trois fonctions optionnelles :

ChampAppelé quand
onEnter()Au moment d'entrer dans cet état.
onUpdate(dt)Chaque frame tant que l'état est actif.
onExit()Au moment de quitter cet état.

Exemple — IA d'ennemi simple

lua
local DISTANCE_DETECTION = 250
local DISTANCE_ATTAQUE   = 60

local sm   -- La machine à états (déclarée ici pour y accéder dans les états)
local joueur

function OnInit(entity)
    joueur = World.findByTag("player")

    sm = StateMachine.new({

        -- État 1 : Patrouille
        Patrouille = {
            onEnter = function()
                Anim.play(entity, "walk", true)
                Nav.patrol(entity, entity:getData("points_patrol"))
            end,
            onUpdate = function(dt)
                local pos_j = World.getPosition(joueur)
                local pos_e = World.getPosition(entity)
                local dist  = Math.distance(pos_j.x, pos_j.y, pos_e.x, pos_e.y)

                if dist < DISTANCE_DETECTION then
                    sm:setState("Poursuite")
                end
            end,
            onExit = function()
                Nav.stop(entity)
            end,
        },

        -- État 2 : Poursuite
        Poursuite = {
            onEnter = function()
                Anim.play(entity, "run", true)
            end,
            onUpdate = function(dt)
                local pos_j = World.getPosition(joueur)
                local pos_e = World.getPosition(entity)
                local dist  = Math.distance(pos_j.x, pos_j.y, pos_e.x, pos_e.y)

                if dist > DISTANCE_DETECTION * 1.5 then
                    sm:setState("Patrouille")
                elseif dist < DISTANCE_ATTAQUE then
                    sm:setState("Attaque")
                else
                    Nav.moveTo(entity, pos_j.x, pos_j.y)
                end
            end,
        },

        -- État 3 : Attaque
        Attaque = {
            onEnter = function()
                Nav.stop(entity)
                Anim.play(entity, "attack", false)
                Anim.onFinish(entity, function()
                    sm:setState("Poursuite")
                end)
            end,
            onUpdate = function(dt)
                -- Infliger des dégâts au frame 4 de l'animation
                Anim.onFrame(entity, 4, function()
                    Stats.mod(joueur.id, "Vie", -15)
                end)
            end,
        },

    }, "Patrouille")  -- État de départ
end

function OnUpdate(entity, dt)
    sm:update(dt)
end
