Quest

Système de quêtes — suivre la progression, valider des objectifs, déclencher des récompenses.

Global automatique

API

FonctionDescription
Quest.start(id)Démarre la quête. Ne fait rien si déjà commencée.
Quest.complete(id)Marque la quête comme terminée et déclenche la récompense.
Quest.fail(id)Marque la quête comme échouée.
Quest.isActive(id)Vrai si la quête est en cours.
Quest.isDone(id)Vrai si la quête est terminée (réussie).
Quest.getProgress(id, objectif)Valeur actuelle d'un objectif numérique.
Quest.setProgress(id, objectif, valeur)Définit la valeur d'un objectif.
Quest.addProgress(id, objectif, delta)Ajoute delta à l'objectif (ex : +1 monstre tué).
Quest.getGoal(id, objectif)Valeur cible de l'objectif (définie dans la config).
Configuration : les quêtes sont définies dans data/quests/ (fichiers JSON). Le script se contente de les piloter.

Exemples

lua  ·  Quête "Tuer 5 loups"
-- Donner la quête quand le joueur parle au chasseur
function OnTriggerEnter(entity, other)
    if other:hasTag("player") then
        Quest.start("tuer_loups")
        Notify.show("Nouvelle quête : Tuer 5 loups !")
    end
end

-- Dans le script du loup : compter les morts
function OnDestroy(entity)
    if Quest.isActive("tuer_loups") then
        Quest.addProgress("tuer_loups", "loups_tues", 1)

        local tues  = Quest.getProgress("tuer_loups", "loups_tues")
        local total = Quest.getGoal("tuer_loups", "loups_tues")
        Notify.show("Loups tués : " .. tues .. " / " .. total)

        if tues >= total then
            Quest.complete("tuer_loups")
        end
    end
end

lua  ·  Quête "Récupérer l'épée"
-- Démarrer la quête au dialogue
Quest.start("recuperer_epee")

-- Dans le script du coffre qui contient l'épée
function OnInteract(entity, joueur)
    Inventory.give(joueur, "epee_ancienne")
    Notify.show("Vous avez trouvé l'Épée Ancienne !")

    if Quest.isActive("recuperer_epee") then
        Quest.setProgress("recuperer_epee", "epee_trouvee", 1)
        Quest.complete("recuperer_epee")
    end
end

lua  ·  Réagir à la complétion d'une quête
-- L'EventBus émet "quest_complete" avec l'id de la quête
EventBus.on("quest_complete", function(data)
    if data.id == "tuer_loups" then
        -- Récompenser le joueur
        Inventory.give(joueur, "piece_or", 50)
        Notify.show("Quête terminée ! +50 pièces d'or.")

        -- Mettre à jour le dialogue du chasseur
        Flag.set("quete_loups_terminee")
    end
end)

-- L'EventBus émet aussi "quest_fail"
EventBus.on("quest_fail", function(data)
    if data.id == "escorte_marchande" then
        Notify.show("Échec : le marchand est mort.", "error")
    end
end)
