Notify

Notifications à l'écran et textes flottants au-dessus des entités. S'empilent automatiquement et disparaissent après quelques secondes.

Global automatique
Fonctionnement : Notify émet des événements EventBus ("ui_notification", "floating_text"). C'est votre script HUD qui les écoute et les affiche dans l'UI. Le module gère la logique, pas le rendu.

API

FonctionDescription
Notify.show(texte, opts)Notification en haut d'écran. opts optionnel.
Notify.floatingText(entity, texte, opts)Texte qui flotte au-dessus de l'entité (dégâts, XP…).
Notify.clear()Efface toutes les notifications.

Option (opts)DescriptionDéfaut
colorCouleur CSS : "white", "gold", "red", "lime", "orange", "#ff8800"…"white"
durationDurée d'affichage en secondes.3.0 (1.5 pour floating)
sizeTaille relative du texte.1.0

Exemples

lua  ·  Notifications colorées
-- Basique (blanc, 3 secondes)
Notify.show("Nouvelle zone découverte !")

-- Coloré
Notify.show("Quête terminée !",       { color = "lime" })
Notify.show("Vie faible !",            { color = "orange" })
Notify.show("Vous êtes mort.",         { color = "red" })
Notify.show("Objet légendaire trouvé !", { color = "gold", duration = 6.0 })

-- Grand texte avec durée personnalisée
Notify.show("BOSS VAINCU",             { color = "gold", size = 1.6, duration = 5.0 })

lua  ·  Textes flottants (dégâts, soins, XP)
-- Dégâts reçus
Notify.floatingText(joueur, "-25", { color = "red" })

-- Soin
Notify.floatingText(joueur, "+50 PV", { color = "lime" })

-- XP gagné
Notify.floatingText(joueur, "+120 XP", { color = "gold" })

-- Critique !
Notify.floatingText(ennemi, "CRITIQUE !", { color = "orange", size = 1.4 })

lua  ·  Brancher sur l'UI (dans le script HUD)
-- Le script HUD écoute les événements et les affiche
EventBus.on("ui_notification", function(data)
    UI.setText("hud_notif", data.text)
    -- Appliquer la couleur si votre UI le supporte
    UI.show("hud_notif")
    Timer.after(data.duration, function()
        UI.hide("hud_notif")
    end)
end)

EventBus.on("ui_notification_clear", function()
    UI.hide("hud_notif")
end)

Événements émis

EventBus

ui_notification{ text, duration, color, size }
floating_text{ entityId, text, duration, color, size, x, y }
ui_notification_clear{ }
