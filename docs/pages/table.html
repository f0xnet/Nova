Table

Fonctions utilitaires pour les tableaux Lua — chercher, filtrer, transformer, mélanger des listes.

Global automatique

API

FonctionDescription
Table.contains(t, valeur)Vrai si la valeur est dans le tableau.
Table.find(t, fonction)Retourne (valeur, index) du premier élément pour lequel fonction(elem) est vrai, ou nil, nil.
Table.filter(t, fonction)Retourne un nouveau tableau avec seulement les éléments valides.
Table.map(t, fonction)Retourne un nouveau tableau transformé par la fonction.
Table.reduce(t, fonction, initial)Réduit le tableau à une valeur en accumulant avec fonction(acc, elem).
Table.keys(t)Retourne la liste des clés d'une table (dict ou tableau).
Table.values(t)Retourne la liste des valeurs d'une table.
Table.shuffle(t)Retourne une copie mélangée (Fisher-Yates). N'altère pas l'original.
Table.pick(t)Retourne un élément aléatoire du tableau.
Table.merge(a, b)Fusion shallow : retourne une nouvelle table avec les clés de a et b (b écrase a).
Table.count(t)Nombre de paires dans la table (fonctionne aussi sur les dicts).
Table.reverse(t)Retourne une copie inversée du tableau.
Table.unique(t)Retourne une copie sans doublons (ordre préservé).
Table.flatten(t)Aplatit récursivement les tables imbriquées en une liste plate.
Table.groupBy(t, fonction)Regroupe les éléments par la clé retournée par la fonction.
Table.copy(t)Copie profonde du tableau.
Note : Pour trier un tableau, utilisez la fonction standard Lua table.sort(t, fn) (t minuscule). Table (T majuscule) est le module Nova qui ne fournit pas de tri.

Exemples

lua  ·  Filtrer et chercher
local ennemis = World.findAllByTag("enemy")

-- Garder seulement les ennemis encore en vie
local ennemis_vivants = Table.filter(ennemis, function(e)
    return Stats.get(e.id, "Vie", 0) > 0
end)

-- Trouver l'ennemi le plus proche du joueur
local pos_joueur = joueur:getPosition()
local plus_proche = Table.find(ennemis, function(e)
    return e:getDistance(joueur) < 200
end)

-- Vérifier si une liste contient un item
local inventaire = Inventory.getAll(joueur.id)
if Table.contains(inventaire, "cle_donjon") then
    print("Le joueur a la clé !")
end

lua  ·  Transformer et compter
local ennemis = World.findAllByTag("enemy")

-- Créer une liste de positions
local positions = Table.map(ennemis, function(e)
    return e:getPosition()
end)

-- Trier par distance au joueur — table.sort standard Lua (t minuscule)
table.sort(ennemis, function(a, b)
    return a:getDistance(joueur) < b:getDistance(joueur)
end)

-- Compter les ennemis avec moins de 20 PV
local nb_blesses = #Table.filter(ennemis, function(e)
    return Stats.get(e.id, "Vie", 0) < 20
end)

-- Sommer les PV de tous les ennemis
local total_vie = Table.reduce(ennemis, function(acc, e)
    return acc + Stats.get(e.id, "Vie", 0)
end, 0)

lua  ·  Divers utilitaires
-- Supprimer les doublons dans une liste de tags
local tags    = { "feu", "poison", "feu", "glace", "poison" }
local uniques = Table.unique(tags)   -- { "feu", "poison", "glace" }

-- Mélanger un tableau (copie, l'original est intact)
local joueurs = { "Alice", "Bob", "Carol" }
local ordre   = Table.shuffle(joueurs)

-- Fusion de configurations (override écrase base)
local base     = { vie = 100, mana = 50, vitesse = 80 }
local override = { vie = 200 }
local config   = Table.merge(base, override)
-- config.vie = 200, config.mana = 50, config.vitesse = 80

-- Compter les entrées d'un dict
local quetes_actives = Quest.getActive()
print("Quêtes en cours : " .. Table.count(quetes_actives))

-- Regrouper des drops par type
local drops = Loot.roll("boss")
local par_type = Table.groupBy(drops, function(d)
    return d.item and "objet" or "vide"
end)
