Camera

Contrôler la vue — suivre le joueur, trembler à l'impact, zoomer, créer des déplacements cinématiques.

Global automatique

API

FonctionDescription
Camera.follow(entity)La caméra suit cette entité à chaque frame. Passer nil pour libérer.
Camera.unfollow()Arrête le suivi d'entité.
Camera.setPosition(x, y)Téléporte la caméra (désactive le follow).
Camera.getPosition()Position actuelle de la caméra.
Camera.moveTo(x, y, duree, easing)Déplace la caméra en douceur sur la durée.
Camera.shake(duree, force)Tremblement d'écran. Force = amplitude en pixels.
Camera.setZoom(scale)Zoom. 1.0 = normal, 2.0 = zoomé ×2, 0.5 = dézoomé.
Camera.getZoom()Zoom actuel.
Camera.zoomTo(scale, duree, easing)Zoom animé en douceur.
Camera.path(waypoints, vitesse, easing, onFin)Déplace la caméra le long d'une liste de points [{x,y}...].
Camera.reset()Réinitialise le zoom, libère le follow et le path.

Exemple — Usage courant

lua
-- Suivi du joueur (à mettre dans init du script joueur ou de la scène)
Camera.follow(World.findByTag("player"))

-- Tremblement lors d'une explosion
EventBus.on("explosion", function(data)
    Camera.shake(0.4, 12)
end)

-- Tremblement léger à chaque coup reçu
EventBus.on("joueur_touche", function()
    Camera.shake(0.15, 5)
    SceneFX.flash(Color.new(255, 0, 0, 100), 0.15)
end)

Exemple — Cutscène cinématique

lua
-- Séquence : zoom sur le boss, puis retour au joueur
function lancerCutsecene(boss, joueur)
    Scheduler.start(function()
        -- Stopper le follow, bloquer les contrôles
        Camera.unfollow()
        EventBus.emit("controles_bloques", {})

        -- Aller vers le boss doucement
        Camera.moveTo(
            boss:getPosition().x,
            boss:getPosition().y,
            2.0, "easeInOut"
        )
        Scheduler.wait(2.2)

        -- Zoom dramatique + cri du boss
        Camera.zoomTo(1.8, 0.5, "easeOut")
        Sound.play("data/sounds/boss_rugit.ogg")
        Camera.shake(0.6, 8)
        Scheduler.wait(2.0)

        -- Retour au joueur
        Camera.follow(joueur)
        Camera.zoomTo(1.0, 1.0, "easeInOut")
        Scheduler.wait(1.0)

        -- Débloquer les contrôles, démarrer le combat
        EventBus.emit("controles_liberes", {})
        EventBus.emit("combat_commence", {})
    end)
end
