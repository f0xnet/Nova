Flag

Drapeaux booléens nommés pour suivre l'état du monde — quête accomplie, boss vaincu, porte ouverte, secret découvert…

Global automatiqueÉmet des événements
Flag vs Persist : Flag est pour la logique de jeu en cours de session. Persist sauvegarde sur disque et survit au redémarrage. Pour des flags qui doivent survivre entre sessions, combinez les deux.

API

FonctionDescriptionRetour
Flag.set(nom)Active le flag.—
Flag.unset(nom)Désactive le flag.—
Flag.toggle(nom)Inverse l'état du flag.—
Flag.get(nom)Vrai si le flag est actif.bool
Flag.getAll()Table de tous les flags actifs.table
Flag.clearAll()Désactive tous les flags.—

Exemples

lua  ·  Événements du monde
-- Marquer qu'un boss a été vaincu
function bossVaincu()
    Flag.set("boss_souterrain_mort")
    Achievement.unlock("tueur_de_boss")
    EventBus.emit("boss_mort", {})
end

-- Dans le script de la porte du boss
EventBus.on("boss_mort", function()
    if Flag.get("boss_souterrain_mort") then
        Anim.play(porte, "open", false)
        Trigger.remove("porte_boss_fermee")
    end
end)

-- Choisir le dialogue du PNJ selon les flags
function interagirAvecPNJ()
    if Flag.get("village_sauve") then
        Conversation.start("npc_heros")
    elseif Flag.get("quete_acceptee") then
        Conversation.start("npc_rappel")
    else
        Conversation.start("npc_intro")
    end
end

lua  ·  Réagir aux changements de flag
-- Écouter tous les changements de flag
EventBus.on("flag_set", function(data)
    Log.info("Flag activé : " .. data.name)

    if data.name == "coffre_salle3_ouvert" then
        -- Mettre à jour la mini-carte
        EventBus.emit("minimap_update", { zone = "salle3", couleur = "gold" })
    end
end)
