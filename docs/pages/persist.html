Persist

Sauvegarde et chargement de données — stocker des valeurs entre les sessions de jeu (scores, progression, options).

Global automatique

API

FonctionDescription
Persist.set(clé, valeur)Enregistre une valeur (nombre, texte, booléen). Sauvegardé sur disque automatiquement.
Persist.get(clé, défaut)Lit une valeur. Retourne défaut si la clé n'existe pas.
Persist.delete(clé)Supprime une entrée.
Persist.has(clé)Vrai si la clé existe.
Persist.getAll()Retourne un tableau de toutes les clés enregistrées.
Persist.clear()Efface toutes les données sauvegardées.
Types supportés : nombres, textes (string), booléens. Les tables Lua ne sont pas supportées directement — sérialisez-les avec Data.encode / Data.decode.

Exemples

lua  ·  Sauvegarder et charger la progression
-- Sauvegarder le meilleur score
local score_actuel = 4280
local meilleur     = Persist.get("meilleur_score", 0)

if score_actuel > meilleur then
    Persist.set("meilleur_score", score_actuel)
    Notify.show("Nouveau record : " .. score_actuel .. " !",  { color = "lime" })
end

-- Sauvegarder la scène actuelle pour reprendre plus tard
Persist.set("derniere_scene",    Scene.current())
Persist.set("joueur_x",         pos.x)
Persist.set("joueur_y",         pos.y)
Persist.set("joueur_vie",       Stats.get(joueur.id, "Vie", 100))

-- Reprendre la partie
local scene = Persist.get("derniere_scene", "ville_principale")
local px    = Persist.get("joueur_x", 0)
local py    = Persist.get("joueur_y", 0)

Scene.setActive(scene)
World.setPosition(joueur, px, py)

lua  ·  Options de jeu persistantes
-- Charger les options au démarrage
local volume_musique = Persist.get("option_volume_musique", 0.8)
local volume_sons    = Persist.get("option_volume_sons",    1.0)
local plein_ecran    = Persist.get("option_plein_ecran",    false)

Sound.setMusicVolume(volume_musique)
Sound.setVolume(volume_sons)

-- Sauvegarder quand le joueur change une option
function changerVolumeMusique(nouvelle_valeur)
    Persist.set("option_volume_musique", nouvelle_valeur)
    Sound.setMusicVolume(nouvelle_valeur)
end

-- Réinitialiser toutes les options
function reinitialiserOptions()
    Persist.delete("option_volume_musique")
    Persist.delete("option_volume_sons")
    Persist.delete("option_plein_ecran")
    Notify.show("Options réinitialisées.")
end

lua  ·  Effacer la sauvegarde (nouveau jeu)
function nouveauJeu()
    -- Effacer toute la progression
    Persist.clear()

    -- Ou effacer seulement certaines clés
    Persist.delete("derniere_scene")
    Persist.delete("joueur_x")
    Persist.delete("joueur_y")

    -- Repartir depuis le début
    Scene.transition("intro", { fade = true, duration = 1.0 })
end
