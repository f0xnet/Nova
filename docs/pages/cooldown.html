Cooldown

Limiter la fréquence d'une action — attaque, soin, sort — avec une période de recharge par entité et par action.

Global automatique

API

FonctionDescriptionRetour
Cooldown.use(entityId, action, duree)Vérifie si prêt ET démarre la recharge. C'est la fonction principale — utilisez celle-ci dans la plupart des cas.true si prêt
Cooldown.isReady(entityId, action)Vrai si l'action n'est pas en recharge.bool
Cooldown.getRemaining(entityId, action)Secondes restantes avant que l'action soit disponible (0 si prêt).number
Cooldown.start(entityId, action, duree)Démarre une recharge sans vérifier si elle était prête.—
Cooldown.reset(entityId, action)Annule la recharge immédiatement (l'action redevient disponible).—
Cooldown.resetAll(entityId)Annule toutes les recharges d'une entité.—
entityId peut être une entité entière (entity) ou juste son ID (entity.id). Les deux fonctionnent.

Exemple — Système de combat

lua
function OnUpdate(entity, dt)
    -- ── Attaque de base : toutes les 0.8 secondes ──
    if InputBind.isJustPressed("attaque") then
        if Cooldown.use(entity.id, "attaque", 0.8) then
            lancerAttaque(entity)
        else
            -- Informer le joueur du temps restant
            local restant = Cooldown.getRemaining(entity.id, "attaque")
            Notify.show(string.format("Attaque dans %.1fs", restant), { duration = 0.5 })
        end
    end

    -- ── Soin : toutes les 10 secondes ──
    if InputBind.isJustPressed("soin") then
        if Cooldown.use(entity.id, "soin", 10.0) then
            Stats.mod(entity.id, "Vie", 50)
            Sound.play("data/sounds/soin.ogg")
            Particles.emit(World.getPosition(entity).x, World.getPosition(entity).y, {
                count = 15, color = Color.new(0, 255, 100), speed = 60, lifetime = 0.8
            })
        end
    end

    -- ── Dash : toutes les 3 secondes ──
    if InputBind.isJustPressed("dash") then
        if Cooldown.use(entity.id, "dash", 3.0) then
            faireUnDash(entity)
        end
    end
end

-- En cas de mort : réinitialiser toutes les recharges
function OnMessage(entity, msg, data)
    if msg == "ressuciter" then
        Cooldown.resetAll(entity.id)
    end
end
