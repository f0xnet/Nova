Démarrer avec Nova Script

Tout ce qu'il faut savoir pour écrire votre premier script de jeu.

C'est quoi un script ?

Un script est un fichier .lua attaché à une entité (joueur, ennemi, objet…). Il définit le comportement de cette entité : que fait-elle à chaque frame ? Comment réagit-elle aux coups ? Aux touches du joueur ?


Aucun require() nécessaire. Tous les modules Nova (Timer, World, Sound, etc.) sont disponibles partout, directement, comme des variables globales.

Les fonctions du cycle de vie

Un script peut définir ces fonctions — Nova les appellera automatiquement au bon moment. Toutes sont optionnelles : définissez seulement celles dont vous avez besoin.


FonctionQuand est-elle appelée ?
OnInit(entity, props)Une seule fois, au chargement de l'entité. props contient les données du JSON de scène.
OnUpdate(entity, dt)Chaque frame (~60×/seconde). dt = secondes écoulées depuis la frame précédente.
OnDestroy(entity)Quand l'entité est détruite. Idéal pour nettoyer des timers ou des effets.
OnMessage(entity, msg, data)Quand un autre script appelle entity:sendMessage(msg, data).
OnKeyDown(key)À chaque appui de touche (une seule fois par appui).
OnKeyUp(key)À chaque relâchement de touche.
OnCollisionEnter(entityId)Quand cette entité entre en contact avec une autre.
OnCollisionExit(entityId)Quand le contact se termine.

Votre premier script complet

Un ennemi simple qui suit le joueur et lui inflige des dégâts.


lua  ·  scripts/ennemi_simple.lua
-- Variables locales au script (invisibles depuis l'extérieur)
local vie      = 30    -- points de vie de cet ennemi
local vitesse  = 80    -- pixels par seconde
local portee   = 100   -- distance pour détecter le joueur

-- ─── Initialisation ────────────────────────────────────────────
function OnInit(entity, props)
    -- props vient du JSON de scène, ex: "props": { "vie": 50 }
    vie     = props.vie     or 30
    vitesse = props.vitesse or 80

    -- Jouer l'animation de repos au démarrage
    Anim.play(entity, "idle", true)
end

-- ─── Mise à jour chaque frame ──────────────────────────────────
function OnUpdate(entity, dt)
    -- Trouver le joueur dans la scène
    local joueur = World.findByTag("player")
    if not joueur then return end  -- pas de joueur = rien à faire

    local distance = World.distance(entity, joueur)

    if distance < portee then
        -- Le joueur est proche : poursuivre
        Nav.moveTo(entity, joueur, vitesse)
        Anim.play(entity, "run", true)

        if distance < 30 then
            -- Le joueur est à portée d'attaque
            if Cooldown.use(entity.id, "attaque", 1.0) then
                joueur:sendMessage("takeDamage", { amount = 10 })
                Sound.play("data/sounds/hit.ogg")
            end
        end
    else
        -- Joueur trop loin : rester sur place
        Nav.stop(entity)
        Anim.play(entity, "idle", true)
    end
end

-- ─── Réception de messages ────────────────────────────────────
function OnMessage(entity, msg, data)
    if msg == "takeDamage" then
        vie = vie - data.amount

        -- Flash rouge pour signaler le dégât
        Notify.floatingText(entity, "-" .. data.amount, { color = "red" })

        if vie <= 0 then
            -- L'ennemi est mort
            Sound.play("data/sounds/mort.ogg")
            Particles.emit(
                World.getPosition(entity).x,
                World.getPosition(entity).y,
                { count = 20, speed = 150, lifetime = 0.6 }
            )
            EntityState.disable(entity)  -- reste mort entre les sessions
        end
    end
end

Ce qu'on peut faire avec une entité

MéthodeDescription
entity:getTransform()Retourne la position, rotation, échelle
entity:getPosition()Raccourci → {x, y}
entity:getTag()Retourne le composant tag (.tag = la chaîne)
entity:getCollider()Retourne le collider (.size, .radius, .enabled)

Les règles d'or

🟢 dt (delta time) — Multipliez toujours les vitesses par dt dans OnUpdate. Sans ça, le jeu ira plus vite sur les PC rapides.
🟢 Variables locales — Déclarez les variables avec local en dehors des fonctions pour qu'elles persistent entre les frames.
⚠️ Vérifiez nil — World.findByTag() peut retourner nil si l'entité n'existe pas. Vérifiez toujours avant d'utiliser le résultat.
💡 Pas de require() — Timer, Sound, World, etc. sont déjà disponibles. Utilisez-les directement.
