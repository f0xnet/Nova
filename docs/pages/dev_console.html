DevConsole

Console développeur in-game. Ouvrir avec N, fermer avec Echap. Taper help pour lister les commandes disponibles.

nova/dev_console require
Chargement : la console est chargée automatiquement par main.lua via require("nova/dev_console"). Elle n'a pas besoin d'être importée manuellement dans vos scripts.

API Lua

Accessible depuis n'importe quel script via la variable globale DevConsole (exposée par main.lua).

FonctionDescriptionRetour
DevConsole.open()Ouvre la console.—
DevConsole.close()Ferme la console.—
DevConsole.toggle()Bascule l'état ouvert/fermé.—
DevConsole.isOpen()Retourne true si la console est ouverte.bool
DevConsole.print(text)Ajoute une ou plusieurs lignes dans la sortie de la console. Les sauts de ligne \n sont gérés.—
DevConsole.register(name, fn, help)Enregistre une nouvelle commande. name est insensible à la casse. fn reçoit un tableau d'arguments (strings). help est la description affichée par help <cmd>.—
DevConsole.execute(raw)Exécute une chaîne de commande comme si l'utilisateur l'avait tapée.—

Ajouter une commande personnalisée

lua  ·  Enregistrer une commande depuis un script
-- Dans n'importe quel script, après que main.lua est chargé :
DevConsole.register("god", function(args)
    local on = (args[1] ~= "off")
    Stats.set(World.findByTag("player").id, "invincible", on and 1 or 0)
    DevConsole.print("  Mode god : " .. (on and "ON" or "OFF"))
end, "god [off] — active/désactive l'invincibilité")

-- Utilisation dans la console :
--   god       →  Mode god : ON
--   god off   →  Mode god : OFF

lua  ·  Afficher des informations depuis un script
-- Envoyer des messages de debug vers la console in-game :
DevConsole.print("Ennemi spawné : id=" .. tostring(entity.id))

-- Afficher une table formatée :
local stats = Stats.getAll(entity.id)
for k, v in pairs(stats) do
    DevConsole.print(string.format("  %s = %s", k, tostring(v)))
end

lua  ·  Évaluer du Lua à la volée
-- Depuis la console in-game (commande lua) :
lua Time.getHour()
-- → = 14

lua Stats.mod(World.findByTag("player").id, "Vie", 100)
-- → (aucun retour : nil ignoré)

lua DevConsole.print(Debug.inspect(World.findByTag("player")))
-- → affiche les propriétés de l'entité joueur

lua  ·  Afficher les erreurs Lua en direct
-- Le moteur émet "script_error" pour toute erreur Lua (load, init,
-- update, render, named handler...). À brancher au démarrage pour
-- voir les erreurs directement dans la console dev :
EventBus.on("script_error", function(d)
    DevConsole.print(string.format("[%s] %s", d.phase, d.path))
    DevConsole.print("  " .. d.error)
end)

Architecture

La console est un module Lua pur (nova/dev_console.lua) sans modification du C++. Elle utilise les mêmes APIs que les scripts de scène :

  • Debug.fillRect / Debug.label pour le rendu superposé.
  • Viewport.getWindowSize() pour s'adapter à la résolution.
  • Input.isKeyPressed() pour la détection Shift lors de la saisie.

DevConsole.draw() est appelé à chaque frame depuis update(dt) dans main.lua. Quand la console est fermée, la fonction retourne immédiatement sans aucun coût.

Color.new() obligatoire : utiliser Color(...) directement (sans .new) ne fonctionne pas avec la version de sol2 intégrée au moteur — l'erreur est silencieuse. Toujours utiliser Color.new(r, g, b, a).
