Loot

Butin aléatoire — définir des tables de loot avec garantis et tirages pondérés, faire tomber des objets à la mort d'un ennemi.

Global automatique

API

FonctionDescription
Loot.define(id, table)Déclare une table de loot avec un identifiant. À appeler une seule fois (démarrage).
Loot.roll(id, nb, ctx)Tire nb fois dans la table. Retourne une liste { {item, quantity}, ... }. nb et ctx optionnels.
Loot.rollOne(id, ctx)Tire une seule fois. Retourne { item, quantity } ou nil.
Loot.dropFor(entity, id, ctx)Tire le loot et l'ajoute directement à l'inventaire de l'entité.

Structure d'une table de loot

ChampDescription
guaranteedListe d'objets toujours inclus dans le butin.
poolListe d'objets en tirage pondéré. Un seul est sélectionné par tirage.
rollsNombre de tirages dans pool (défaut : 1).

Champ d'une entréeDescription
itemIdentifiant de l'objet. nil = rien (bonne pratique pour régler les chances).
weightPoids relatif dans le tirage. Plus c'est grand, plus c'est probable.
quantityNombre ou { min = N, max = M } pour une quantité variable.
condFonction optionnelle (ctx) → bool — l'entrée n'est eligible que si cond(ctx) est vrai.

Exemples

lua  ·  Définir et utiliser une table de loot
-- Définir au démarrage (script global)
Loot.define("gobelin", {
    -- Toujours inclus
    guaranteed = {
        { item = "piece_or", quantity = { min = 1, max = 5 } },
    },
    -- Tirage unique parmi ces entrées
    pool = {
        { item = "potion_soin",  weight = 30 },
        { item = "cle_rouille",  weight = 10 },
        { item = "epee_gobelin", weight = 5  },
        { item = nil,            weight = 55 },   -- 55% de ne rien avoir en plus
    },
})

-- À la mort du gobelin : donner le butin au joueur
function OnStatZeroed(entityId, stat)
    if stat == "Vie" then
        local joueur = World.findByTag("player")
        if joueur then
            Loot.dropFor(joueur, "gobelin")
        end
    end
end

lua  ·  Coffre avec plusieurs tirages et condition
Loot.define("coffre_boss", {
    guaranteed = {
        { item = "piece_or", quantity = { min = 50, max = 150 } },
    },
    pool = {
        { item = "armure_rare", weight = 20 },
        { item = "epee_rare",   weight = 20 },
        -- Objet bonus seulement en mode difficile
        { item = "legendaire",  weight = 10,
          cond = function(ctx) return ctx and ctx.difficulte == "hard" end },
        { item = nil,           weight = 50 },
    },
    rolls = 2,   -- 2 tirages dans le pool
})

-- Ouvrir le coffre
function OnActivate(activatorId, actionID)
    local joueur = Registry:getEntity(activatorId)
    local ctx    = { difficulte = Persist.get("difficulte", "normal") }

    Loot.dropFor(joueur, "coffre_boss", ctx)
    Notify.show("Coffre ouvert !", { color = "gold" })
    entity:disable()
end

lua  ·  Vérifier ce qui a été tiré
-- Loot.roll retourne la liste des drops
local drops = Loot.roll("gobelin")
for _, drop in ipairs(drops) do
    if drop.item then
        print("Drop : " .. drop.item .. " x" .. drop.quantity)
        Notify.show("Obtenu : " .. drop.item, { color = "gold" })
    end
end
