Loot

Butin aléatoire — définir des tables de loot avec probabilités et faire tomber des objets à la mort d'un ennemi.

Global automatique

API

FonctionDescription
Loot.define(id, table)Déclare une table de loot avec un identifiant. À appeler une seule fois (démarrage).
Loot.roll(id, nb, ctx)Tire au sort nb objets dans la table. Retourne une liste. nb et ctx sont optionnels.
Loot.rollOne(id, ctx)Tire un seul objet. Retourne une table item ou nil.
Loot.dropFor(entity, id, ctx)Fait apparaître le loot dans le monde à la position de l'entité.
Flux typique : définir la table de loot au démarrage avec Loot.define(), puis appeler Loot.dropFor() ou Loot.roll() quand nécessaire.

Exemples

lua  ·  Définir et utiliser une table de loot
-- Dans le script global ou de démarrage : définir une seule fois
Loot.define("gobelin", {
    { id = "piece_or",     weight = 60, count = { min = 1, max = 5 } },
    { id = "potion_soin",  weight = 25 },
    { id = "cle_rouille",  weight = 10 },
    { id = "epee_gobelin", weight = 5  },
})

-- Dans le script du gobelin, à sa mort
function OnDestroy(entity)
    -- Faire apparaître le loot à la position du gobelin
    Loot.dropFor(entity, "gobelin")
end

lua  ·  Récupérer le loot sans le faire apparaître
-- Tirer un objet et l'ajouter directement à l'inventaire
function OnDestroy(entity)
    local item = Loot.rollOne("gobelin")

    if item then
        -- item.id = identifiant de l'objet
        Inventory.add(joueur.id, item.id, item.count or 1)
        Notify.show("Obtenu : " .. item.id)
    end
end

-- Tirer plusieurs objets (pour un coffre)
local items = Loot.roll("coffre_boss", 3)
for _, item in ipairs(items) do
    Inventory.add(joueur.id, item.id, item.count or 1)
end

lua  ·  Tables de loot variées
-- Définir plusieurs tables
Loot.define("squelette", {
    { id = "os",          weight = 70 },
    { id = "piece_or",    weight = 20, count = { min = 1, max = 3 } },
    { id = "hache_rouee", weight = 10 },
})

Loot.define("coffre_commun", {
    { id = "piece_or",    weight = 100, count = { min = 10, max = 30 } },
    { id = "potion_soin", weight = 50 },
    { id = "epee_longue", weight = 15 },
})

Loot.define("coffre_boss", {
    { id = "piece_or",    weight = 100, count = { min = 100, max = 200 } },
    { id = "armure_rare", weight = 30 },
    { id = "cle_tresor",  weight = 80 },
})
