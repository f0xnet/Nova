Notify

Notifications à l'écran — messages de jeu, alertes, confirmations. S'empilent automatiquement et disparaissent après quelques secondes.

Global automatique

API

FonctionDescription
Notify.show(texte)Affiche une notification info (bleue) pendant 3 secondes.
Notify.show(texte, type)Type : "info", "success", "warn", "error".
Notify.show(texte, type, duree)Durée en secondes avant disparition.
Notify.clear()Efface toutes les notifications à l'écran.

Exemples

lua  ·  Notifications courantes
-- Info basique (bleu, 3 sec)
Notify.show("Nouvelle zone découverte !")

-- Succès (vert)
Notify.show("Quête terminée !", "success")

-- Avertissement (orange)
Notify.show("Vie faible !", "warn")

-- Erreur (rouge)
Notify.show("Inventaire plein !", "error")

-- Durée personnalisée (10 secondes)
Notify.show("Boss apparu au nord !", "warn", 10)

lua  ·  Notifications de jeu intégrées
-- Ramasser un objet
function OnInteract(entity, joueur)
    local nom = entity:getData("nom")
    Inventory.give(joueur, entity:getData("id_item"))
    Notify.show("Obtenu : " .. nom, "success")
    entity:disable()
end

-- Vie basse
EventBus.on("stat_zeroed", function(data)
    if data.stat == "Vie" then
        Notify.show("Le joueur est mort !", "error")
    end
end)

-- Atteindre un niveau
EventBus.on("level_up", function(data)
    Notify.show("Niveau " .. data.niveau .. " atteint !", "success", 5)
end)
