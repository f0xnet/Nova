Physics

Requêtes physiques — tester des chevauchements, trouver les entités proches, lancer des rayons de détection.

Global automatique
Note : Physics sert à interroger le monde physique (qui touche quoi, qui est proche). Pour déplacer des entités, utilisez entity:setPosition() ou Nav.moveTo().

API

FonctionDescription
Physics.findInRadius(origine, rayon, tag)Retourne toutes les entités avec ce tag dans le rayon autour de origine (entité). Tag optionnel.
Physics.nearest(origine, rayon, tag)Retourne l'entité la plus proche et sa distance (entité, distance).
Physics.overlap(entityA, entityB)Vrai si les deux entités se chevauchent.
Physics.overlapPoint(x, y, tag)Retourne toutes les entités dont le collider contient le point (x, y).
Physics.raycast(ox, oy, dx, dy, distMax, tag)Lance un rayon depuis (ox,oy) dans la direction (dx,dy). Retourne (entité, distance) ou nil.

Exemples

lua  ·  Zone d'explosion (dégâts en cercle)
function exploser(entity_source)
    local pos = entity_source:getPosition()
    Particles.emit(pos.x, pos.y, { count = 40, speed = 250, spread = 360,
                                    color = Color.new(255, 140, 0), gravity = 80 })
    Camera.shake(0.5, 15)
    Sound.play("data/sounds/explosion.ogg")

    -- Toucher tout ce qui est dans 120 pixels
    local victimes = Physics.findInRadius(entity_source, 120, "damageable")
    for _, victime in ipairs(victimes) do
        Stats.mod(victime.id, "Vie", -50)
    end
end

lua  ·  Trouver l'ennemi le plus proche
function attaquerLePlusProche(entity)
    local cible, dist = Physics.nearest(entity, 200, "enemy")

    if cible then
        Stats.mod(cible.id, "Vie", -25)
        Camera.shake(0.1, 3)
    end
end

lua  ·  Ligne de vue (raycast)
function peutVoirJoueur(entity, joueur)
    local pos_e = entity:getPosition()
    local pos_j = joueur:getPosition()

    -- Direction vers le joueur
    local dx = pos_j.x - pos_e.x
    local dy = pos_j.y - pos_e.y

    -- Lancer un rayon sur 300 pixels, ignorer les ennemis
    local cible, dist = Physics.raycast(pos_e.x, pos_e.y, dx, dy, 300, "player")

    -- Si on touche le joueur en premier : ligne de vue dégagée
    return cible ~= nil
end

lua  ·  Détecter si un point est dans un collider
-- Quand la souris est cliquée, sélectionner l'entité sous le curseur
if InputEx.isMouseJustPressed("left") then
    local souris   = Input.getMousePosition()
    local entites  = Physics.overlapPoint(souris.x, souris.y)

    if #entites > 0 then
        print("Entité cliquée : " .. entites[1].tag)
    end
end
