Input

Lire les entrées clavier et souris — touches enfoncées, clics, position de la souris.

Global automatique

API — Clavier

FonctionDescription
Input.isKeyPressed(touche)Vrai tant que la touche est maintenue.

API — Souris

FonctionDescription
Input.isMouseButtonPressed(bouton)Vrai si le bouton est enfoncé. Valeurs : "left", "right", "middle".
Input.getMousePosition()Retourne la position de la souris dans le monde (Vec2f).

API — InputEx (événements instantanés)

InputEx détecte ce qui se passe exactement sur ce frame — utile pour réagir à une pression sans répétition.

FonctionDescription
InputEx.isKeyJustPressed(touche)Vrai uniquement le premier frame où la touche est pressée.
InputEx.isKeyJustReleased(touche)Vrai uniquement le frame où la touche est relâchée.
InputEx.isMouseJustPressed(bouton)Vrai uniquement le premier frame du clic.
InputEx.isMouseJustReleased(bouton)Vrai uniquement le frame du relâchement.
InputEx.getJustPressedKeys()Tableau de toutes les touches pressées ce frame.

Touches disponibles

"A" … "Z", "0" … "9"
"Escape", "Space", "Enter", "Backspace", "Tab"
"Left", "Right", "Up", "Down"
"LShift", "RShift", "LControl", "RControl", "LAlt", "RAlt"

Exemples

lua  ·  Déplacement clavier 4 directions
local VITESSE = 200

function update(entity, dt)
    local dx, dy = 0, 0

    if Input.isKeyPressed("Left")  or Input.isKeyPressed("A") then dx = -1 end
    if Input.isKeyPressed("Right") or Input.isKeyPressed("D") then dx =  1 end
    if Input.isKeyPressed("Up")    or Input.isKeyPressed("W") then dy = -1 end
    if Input.isKeyPressed("Down")  or Input.isKeyPressed("S") then dy =  1 end

    -- Normaliser pour ne pas aller plus vite en diagonale
    if dx ~= 0 and dy ~= 0 then
        dx = dx * 0.707
        dy = dy * 0.707
    end

    local pos = entity:getPosition()
    entity:setPosition(pos.x + dx * VITESSE * dt,
                       pos.y + dy * VITESSE * dt)
end

lua  ·  Attaque au clic souris
function update(entity, dt)
    -- Tirer vers la souris au clic gauche (une seule fois par clic)
    if InputEx.isMouseJustPressed("left") then
        local pos    = entity:getPosition()
        local souris = Input.getMousePosition()
        local angle  = Math.angleTo(pos.x, pos.y, souris.x, souris.y)

        Projectile.fire(pos.x, pos.y, {
            angle    = angle,
            speed    = 400,
            lifetime = 2.0,
        })
    end

    -- Ouvrir l'inventaire (une seule fois par pression)
    if InputEx.isKeyJustPressed("I") then
        EventBus.emit("inventaire_toggle", {})
    end
end
