Easing

Fonctions de lissage Robert Penner complètes — interpolation manuelle avec courbes (utile si vous n'utilisez pas Tween).

Global automatique
Conseil : dans la plupart des cas, utilisez Tween plutôt qu'Easing directement. Easing est utile quand vous calculez manuellement une valeur dans update.

Helpers

FonctionDescription
Easing.apply(nom, t)Applique la courbe nommée à t ∈ [0, 1]. Retourne une valeur entre 0 et 1.
Easing.get(nom)Retourne la fonction de courbe par son nom (ou Easing.linear si inconnu).
Easing.lerp(a, b, t, nom)Interpolation de a vers b avec la courbe nommée.

Courbes disponibles

NomEffet
"linear"Vitesse constante.
"inQuad" / "outQuad" / "inOutQuad"Accélération quadratique (douce).
"inCubic" / "outCubic" / "inOutCubic"Accélération cubique (marquée).
"inQuart" / "outQuart" / "inOutQuart"Accélération quartique.
"inQuint" / "outQuint" / "inOutQuint"Accélération quintique.
"inSine" / "outSine" / "inOutSine"Courbe sinusoïdale.
"inExpo" / "outExpo" / "inOutExpo"Accélération exponentielle (très vive).
"inCirc" / "outCirc" / "inOutCirc"Courbe circulaire.
"inElastic" / "outElastic" / "inOutElastic"Vibration élastique.
"inBack" / "outBack" / "inOutBack"Recul avant de partir / dépasse avant de s'arrêter.
"inBounce" / "outBounce" / "inOutBounce"Rebonds.
Noms différents de Tween : Tween utilise des alias courts ("easeIn", "easeOut"…). Easing utilise les noms complets Robert Penner ("inQuad", "outCubic"…). Ne pas confondre.

Exemple — Animation manuelle dans update

lua  ·  Faire apparaître un panneau avec rebond
local duree     = 0.6   -- secondes
local temps     = 0
local debut_y   = -200  -- hors écran (au-dessus)
local arrivee_y = 50    -- position finale

function update(entity, dt)
    if temps < duree then
        temps = temps + dt
        local t = math.min(temps / duree, 1.0)
        local y = Easing.lerp(debut_y, arrivee_y, t, "outBounce")
        entity:setPosition(400, y)
    end
end

lua  ·  Obtenir une fonction par nom
-- Récupérer la fonction une seule fois (plus efficace dans une boucle)
local fn = Easing.get("outElastic")
for i = 0, 10 do
    local t = i / 10
    local v = fn(t)  -- v ∈ [0, 1]
    -- utiliser v pour animer…
end

-- Équivalent direct
local v = Easing.apply("inOutCubic", 0.75)
