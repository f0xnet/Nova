Spatial

Recherches spatiales rapides — trouver les entités dans un rayon ou un rectangle, compter par tag.

Global automatique
Spatial vs Physics : Spatial utilise une grille interne et cherche par position dans le monde. Physics interroge les colliders réels. Pour des zones de dégâts précises, préférez Physics.findInRadius().

API

FonctionDescription
Spatial.findInRadius(x, y, rayon, tag)Retourne toutes les entités avec ce tag dans le rayon. Tag optionnel.
Spatial.findInRect(x, y, w, h, tag)Retourne toutes les entités dans le rectangle.
Spatial.nearest(x, y, tag)Retourne l'entité la plus proche et sa distance : (entité, distance).
Spatial.findAt(cellX, cellY, tag)Retourne les entités dans la cellule de grille donnée. Tag optionnel.
Spatial.count(tag)Nombre total d'entités actives avec ce tag. Tag optionnel (nil = toutes).
Spatial.CELL_SIZETaille de cellule de la grille en pixels (défaut : 64). Modifier avant le premier frame pour ajuster la résolution. Valeur plus grande = moins de cellules mais requêtes plus grossières.

Exemples

lua  ·  Explosion en zone
function exploser(x, y)
    Particles.emit(x, y, { count = 40, speed = 250, spread = 360,
                            color = Color.new(255, 140, 0), gravity = 80 })
    Camera.shake(0.5, 15)
    Sound.play("data/sounds/explosion.ogg")

    -- Toucher tout ce qui est dans 120 pixels
    local victimes = Spatial.findInRadius(x, y, 120, "enemy")
    for _, victime in ipairs(victimes) do
        Stats.mod(victime.id, "Vie", -50)
    end
end

lua  ·  Cibler l'ennemi le plus proche
function attaquerLePlusProche(entity)
    local pos = entity:getPosition()

    -- nearest retourne (entité, distance)
    local cible, dist = Spatial.nearest(pos.x, pos.y, "enemy")

    if cible and dist < 150 then
        Stats.mod(cible.id, "Vie", -25)
    end
end

lua  ·  Compter les ennemis sur la carte
-- Vérifier si tous les ennemis sont vaincus
function update(entity, dt)
    local nb_ennemis = Spatial.count("enemy")

    if nb_ennemis == 0 then
        EventBus.emit("salle_videe", {})
        Timer.after(1.0, function()
            EventBus.emit("ouvrir_porte_sortie", {})
        end)
    end

    Debug.watch("ennemis_restants", nb_ennemis)
end
