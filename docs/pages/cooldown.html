Cooldown

Empêcher de spammer des actions — attaque, sort, dash, interaction. Chaque entité a ses propres cooldowns.

Global automatique

API

FonctionDescription
Cooldown.use(entityId, action, duree)Déclenche le cooldown si prêt. Retourne true si l'action a pu être utilisée.
Cooldown.start(entityId, action, duree)Démarre le cooldown sans vérifier s'il est prêt.
Cooldown.isReady(entityId, action)Vrai si le cooldown est terminé (action disponible).
Cooldown.getRemaining(entityId, action)Secondes restantes avant que l'action soit disponible.
Cooldown.getProgress(entityId, action, duree)Progression de 0.0 à 1.0 (utile pour les barres d'UI).
Cooldown.reset(entityId, action)Remet le cooldown à zéro immédiatement.
Cooldown.resetAll(entityId)Réinitialise tous les cooldowns de cette entité.
Cooldown.update(dt)Fait avancer tous les timers. Appelé automatiquement par ScriptSystem chaque frame — ne pas appeler manuellement.
Nettoyage automatique : à la destruction d'une entité (entity_destroyed), tous ses cooldowns sont annulés automatiquement via Cooldown.resetAll(entityId).
entityId : passez toujours entity.id comme premier argument. Chaque entité a ses cooldowns indépendants.

Événements émis

EventBus

cooldown_ready{ entityId, action } — quand un cooldown expire naturellement (non annulé)
lua  ·  Réagir à la fin d'un cooldown
-- Notifier le joueur quand son ultime est de nouveau disponible
EventBus.on("cooldown_ready", function(data)
    if data.entityId == joueur.id and data.action == "ultime" then
        Notify.show("Ultime disponible !", { color = "gold" })
        Sound.play("data/sounds/ready.ogg")
    end
end)

Exemples

lua  ·  Attaque avec cooldown
local COOLDOWN_ATTAQUE = 0.5  -- secondes

function update(entity, dt)
    if InputBind.isJustPressed("attaquer") then
        -- Cooldown.use retourne true seulement si l'action est disponible
        if Cooldown.use(entity.id, "attaque", COOLDOWN_ATTAQUE) then
            attaquer(entity)
        end
    end
end

function attaquer(entity)
    Anim.play(entity, "attack", false)
    Sound.play("data/sounds/epee.ogg")
    -- ...
end

lua  ·  Soin automatique avec cooldown
local COOLDOWN_SOIN = 8.0   -- secondes entre chaque soin
local SEUIL_VIE    = 30     -- se soigne sous 30 PV

function update(entity, dt)
    local vie = Stats.get(entity.id, "Vie", 0)

    if vie < SEUIL_VIE and Cooldown.isReady(entity.id, "soin_auto") then
        Cooldown.start(entity.id, "soin_auto", COOLDOWN_SOIN)
        Stats.mod(entity.id, "Vie", 25)

        local pos = entity:getPosition()
        Particles.emit(pos.x, pos.y, {
            count = 8, speed = 50, spread = 360,
            color = Color.new(0, 255, 150),
        })
    end

    -- Afficher le temps restant en debug
    local restant = Cooldown.getRemaining(entity.id, "soin_auto")
    if restant > 0 then
        Debug.watch("soin_dans", string.format("%.1f s", restant))
    end
end

lua  ·  Barre de recharge UI
local COOLDOWN_DASH = 2.0

function update(entity, dt)
    if InputBind.isJustPressed("dash") then
        if Cooldown.use(entity.id, "dash", COOLDOWN_DASH) then
            faireUnDash(entity)
        end
    end

    -- Progression pour afficher dans l'UI (0 = en recharge, 1 = prêt)
    local progression = Cooldown.getProgress(entity.id, "dash", COOLDOWN_DASH)
    UI.setValue("barre_dash", progression)
end
