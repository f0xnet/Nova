Particles

Système de particules 2D — explosions, traînées magiques, pluie, poussière, sang, étincelles.

Global automatique

API

FonctionDescription
Particles.emit(x, y, opts)Burst ponctuel : émet N particules d'un coup à la position (x, y).
Particles.emitter(x, y, opts)Émetteur continu : émet des particules régulièrement. Retourne un handle.
Particles.move(handle, x, y)Déplace un émetteur continu (pour suivre une entité).
Particles.stop(handle)Arrête un émetteur continu.
Particles.clear()Supprime toutes les particules et tous les émetteurs.
Particles.count()Nombre de particules actives.

OptionDescriptionDéfaut
countNombre de particules par burst.12
rateSecondes entre spawns (émetteur continu).0.04
lifetimeDurée de vie en secondes.1.0
speedVitesse max en pixels/seconde.80
spreadDemi-angle de dispersion en degrés. 180 = dans toutes les directions.180
angleDirection centrale. 0=droite, 90=bas, 270=haut.270
gravityGravité en pixels/s². Positif = tombe.0
sizeTaille initiale en pixels.5
sizeEndTaille finale en pixels.0
colorCouleur de départ.Blanc
colorEndCouleur d'arrivée (alpha → 0 par défaut).—

Exemples

lua  ·  Explosion
Particles.emit(x, y, {
    count    = 40,
    speed    = 250,
    spread   = 360,         -- toutes les directions
    lifetime = 0.8,
    size     = 8, sizeEnd = 1,
    color    = Color.new(255, 140, 0),       -- orange
    colorEnd = Color.new(100, 0, 0, 0),      -- rouge transparent
    gravity  = 80,
})

lua  ·  Traînée magique (suit le joueur)
-- Créer l'émetteur
local trainee = Particles.emitter(0, 0, {
    rate     = 0.02,         -- 50 particules/seconde
    count    = 1,
    speed    = 15,
    spread   = 360,
    lifetime = 0.4,
    size     = 5, sizeEnd = 0,
    color    = Color.new(100, 150, 255),  -- bleu-mauve
})

-- Chaque frame : déplacer l'émetteur avec le joueur
function update(entity, dt)
    local pos = World.getPosition(entity)
    Particles.move(trainee, pos.x, pos.y)
end

-- Stopper l'émetteur quand le sort se termine (via un message)
function OnMessage(msg, data)
    if msg == "sort_termine" then
        Particles.stop(trainee)
    end
end

lua  ·  Pluie de pièces
Particles.emit(x, y, {
    count    = 20,
    speed    = 120,
    angle    = 270,          -- vers le haut
    spread   = 60,           -- demi-cône de 60°
    lifetime = 1.2,
    size     = 6, sizeEnd = 4,
    gravity  = 200,          -- retombe vite
    color    = Color.new(255, 215, 0),    -- or
    colorEnd = Color.new(200, 160, 0, 0),
})
