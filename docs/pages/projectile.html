Projectile

Système complet de tirs — flèches, balles, sorts, bombes. Gère automatiquement les collisions, la durée de vie et le recyclage via Pool.

Global automatique
Projectile construit sur Pool. Pas besoin de gérer Pool manuellement — Projectile s'en charge. Un seul appel Projectile.init() + Projectile.fire() et tout fonctionne.

API

FonctionDescriptionRetour
Projectile.init(opts)Crée un pool de projectiles. À appeler une seule fois au démarrage. opts: poolID, count, templateFn—
Projectile.fire(x, y, opts)Tire un projectile depuis (x, y). Retourne l'entité ou nil si le pool est vide.entity
Projectile.release(entity)Libère manuellement un projectile (le remet dans le pool).—
Projectile.activeCount()Nombre de projectiles actuellement en vol.number
Projectile.clearAll()Détruit tous les pools et projectiles.—

Option pour fire()Description
poolIDQuel pool utiliser (défaut: "projectile").
angleDirection en degrés. 0 = droite, 90 = bas, 270 = haut.
speedVitesse en pixels/seconde.
vx, vyVélocité directe en x et y (prioritaire sur angle+speed).
lifetimeDurée de vie en secondes (défaut: 3).
onHit = function(proj, hitEntityId)Appelée lors d'une collision. Appeler Projectile.release(proj) dedans pour détruire.
onExpire = function(proj)Appelée quand le projectile expire (durée de vie dépassée).

Exemple — Système de tir d'un archer

lua  ·  scripts/archer.lua
-- ── Initialiser le pool de flèches (une seule fois) ──
function OnInit(entity, props)
    if not Pool.size("fleche") or Pool.size("fleche") == 0 then
        Projectile.init({
            poolID     = "fleche",
            count      = 16,
            templateFn = function()
                return World.spawn("ArrowEntity")
            end
        })
    end
end

-- ── Tirer une flèche vers le joueur ──
function tirer(entity, cible)
    -- Calculer l'angle vers la cible
    local posArcher = World.getPosition(entity)
    local posCible  = World.getPosition(cible)
    local dx        = posCible.x - posArcher.x
    local dy        = posCible.y - posArcher.y
    local angle     = math.deg(math.atan(dy, dx))

    Sound.play("data/sounds/arc.ogg", 0.7)

    Projectile.fire(posArcher.x, posArcher.y, {
        poolID   = "fleche",
        angle    = angle,
        speed    = 350,
        lifetime = 2.0,

        onHit = function(fleche, hitId)
            -- Infliger des dégâts à l'entité touchée
            Stats.mod(hitId, "Vie", -15)
            Sound.play("data/sounds/impact.ogg")
            Particles.emit(World.getPosition(fleche).x, World.getPosition(fleche).y, {
                count = 6, speed = 80, lifetime = 0.3
            })
            Projectile.release(fleche)   -- remettre dans le pool
        end,

        onExpire = function(fleche)
            -- La flèche a raté : petit effet discret
            Particles.emit(World.getPosition(fleche).x, World.getPosition(fleche).y, {
                count = 3, speed = 40, lifetime = 0.2
            })
        end
    })
end

-- ── IA de l'archer ──
function OnUpdate(entity, dt)
    local joueur = World.findByTag("player")
    if not joueur then return end

    if World.distance(entity, joueur) < 300 then
        if Cooldown.use(entity.id, "tir", 2.0) then
            tirer(entity, joueur)
        end
    end
end
