Sequence

Déclencher une suite d'actions dans un ordre précis — intro de niveau, événement scénaristique, tutoriel guidé.

Global automatique
Sequence vs Scheduler : Scheduler est pour la logique de jeu (IA, combats). Sequence est pensé pour les événements narratifs avec déclencheurs, conditions et étapes nommées.

API

FonctionDescription
Sequence.new(etapes)Crée une séquence à partir d'une liste d'étapes. Retourne un objet séquence.
seq:start()Lance la séquence depuis le début.
seq:stop()Arrête et réinitialise la séquence.
seq:next()Passe à l'étape suivante manuellement.
seq:isRunning()Vrai si la séquence est en cours.
seq:isDone()Vrai si toutes les étapes sont terminées.

Structure d'une étape

ChampDescription
actionFonction exécutée à cette étape.
dureeAttendre N secondes avant de passer à l'étape suivante.
attendreFonction qui retourne vrai quand on peut continuer (attente conditionnelle).

Exemples

lua  ·  Introduction de niveau
local intro = Sequence.new({
    -- Étape 1 : fondu + texte d'ambiance
    {
        action = function()
            EventBus.emit("controles_bloques", {})
            SceneFX.fadeOut(1.0)
            Notify.show("Donjon des Ombres — Niveau 3", "info", 3)
        end,
        duree = 2.0,
    },

    -- Étape 2 : déplacer la caméra vers le danger
    {
        action = function()
            local piege = World.findByTag("premier_piege")
            Camera.moveTo(piege:getPosition().x, piege:getPosition().y, 1.5, "easeInOut")
        end,
        duree = 2.0,
    },

    -- Étape 3 : montrer le piège en action
    {
        action = function()
            EventBus.emit("activer_piege_demo", {})
            Notify.show("Attention aux pièges !", "warn", 2)
        end,
        duree = 2.5,
    },

    -- Étape 4 : retour au joueur
    {
        action = function()
            local joueur = World.findByTag("player")
            Camera.follow(joueur)
            EventBus.emit("controles_liberes", {})
        end,
    },
})

-- Lancer au chargement de la scène
intro:start()

lua  ·  Tutoriel guidé pas à pas
local tuto = Sequence.new({
    { action = function()
        Notify.show("Utilisez ZQSD pour vous déplacer.", "info", 0)
    end,
      -- Attendre que le joueur bouge
      attendre = function()
          return Input.isDown("z") or Input.isDown("q")
              or Input.isDown("s") or Input.isDown("d")
      end },

    { action = function()
        Notify.show("Appuyez sur ESPACE pour attaquer !", "info", 0)
    end,
      attendre = function()
          return Input.isPressed("space")
      end },

    { action = function()
        Notify.show("Bravo ! Tutoriel terminé.", "success")
        Persist.set("tuto_fait", true)
    end },
})

-- Ne lancer le tutoriel que si pas encore fait
if not Persist.get("tuto_fait", false) then
    tuto:start()
end
