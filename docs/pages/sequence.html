Sequence

Déclencher une suite d'actions dans un ordre précis — intro de niveau, événement scénaristique, tutoriel guidé.

Global automatique
Sequence vs Scheduler : Scheduler est pour la logique de jeu en temps réel (IA, combat). Sequence est pensé pour les événements narratifs avec des étapes chaînées et un callback final.
Nettoyage automatique : au changement de scène (scene_changed), toutes les séquences actives sont arrêtées automatiquement. Les callbacks en attente ne se déclenchent pas dans la nouvelle scène.

API

FonctionDescription
Sequence.new()Crée une nouvelle séquence vide. Retourne un objet seq.
seq:call(fn)Appelle une fonction immédiatement.
seq:wait(secondes)Attend N secondes avant de continuer.
seq:tween(secondes, fn)Exécute fn(t) pendant N secondes, avec t allant de 0 à 1.
seq:emit(event, data)Émet un événement EventBus.
seq:dialogue(speaker, text)Affiche une ligne de dialogue.
seq:repeat_(n, fn)Répète une fonction N fois.
seq:play(onComplete)Lance la séquence. onComplete est appelé à la fin.
seq:stop()Arrête la séquence en cours.

Exemples

lua  ·  Introduction de niveau
local intro = Sequence.new()

intro:call(function()
    EventBus.emit("controles_bloques", {})
    SceneFX.fadeOut(1.0)
    Notify.show("Donjon des Ombres — Niveau 3")
end)

intro:wait(2.0)

intro:call(function()
    local piege = World.findByTag("premier_piege")
    local pos   = piege:getPosition()
    Camera.moveTo(pos.x, pos.y, 1.5, "easeInOut")
end)

intro:wait(2.5)

intro:call(function()
    Notify.show("Attention aux pièges !",  { color = "orange" })
    EventBus.emit("activer_piege_demo", {})
end)

intro:wait(2.0)

intro:call(function()
    Camera.follow(World.findByTag("player"))
    EventBus.emit("controles_liberes", {})
end)

-- Lancer la séquence
intro:play()

lua  ·  Tutoriel guidé
local tuto = Sequence.new()

tuto:dialogue("Tutoriel", "Utilisez les touches fléchées pour vous déplacer.")
tuto:wait(3.0)
tuto:dialogue("Tutoriel", "Appuyez sur Espace pour attaquer !")
tuto:wait(2.5)
tuto:call(function()
    Persist.set("tuto_fait", true)
    Notify.show("Tutoriel terminé !",  { color = "lime" })
end)

-- Ne lancer que si le tutoriel n'a pas encore été fait
if not Persist.get("tuto_fait", false) then
    tuto:play()
end

lua  ·  Explosions progressives avec repeat_
local mort_boss = Sequence.new()

mort_boss:repeat_(8, function()
    local pos = boss:getPosition()
    local ox  = Random.float(-80, 80)
    local oy  = Random.float(-80, 80)
    Particles.emit(pos.x + ox, pos.y + oy, {
        count = 30, speed = 200, spread = 360,
        color = Color.new(255, 120, 0),
    })
    Sound.play("data/sounds/explosion.ogg")
end)

mort_boss:wait(0.3)

mort_boss:call(function()
    SceneFX.fadeIn(2.0, function()
        Scene.setActive("fin_de_niveau")
    end)
end)

mort_boss:play()
