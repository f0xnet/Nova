Conversation

Système de dialogues — afficher une suite de répliques, faire des choix, brancher l'histoire selon les flags et l'inventaire.

Global automatique

API

FonctionDescription
Conversation.define(id, arbre)Déclare un dialogue avec un identifiant. À appeler une seule fois.
Conversation.start(id, ctx)Lance le dialogue. ctx (contexte optionnel) est passé aux fonctions de l'arbre.
Conversation.choose(index)Sélectionne un choix quand le dialogue attend une réponse.
Conversation.advance()Passe à la réplique suivante.
Conversation.stop()Ferme le dialogue immédiatement.
Conversation.getCurrent()Retourne le nœud actuel (table avec speaker, text, choices…).
Conversation.isRunning()Vrai si un dialogue est en cours.

Structure d'un arbre de dialogue

Un arbre est une liste de nœuds. Chaque nœud a au minimum un speaker et un text.

ChampDescription
speakerNom du personnage qui parle.
textTexte de la réplique.
choicesListe de choix (optionnel). Chaque choix a un text et un next.
nextIdentifiant du nœud suivant (string). Absent ou nil = fin de la conversation.
onEnterFonction (ctx) appelée quand ce nœud est atteint (optionnel).
condFonction (ctx) → bool sur un choix. Si false, le choix n'est pas affiché.

Exemples

lua  ·  Dialogue simple avec un PNJ
-- Définir le dialogue une seule fois (script global ou init)
Conversation.define("marchand_bonjour", {
    start = "greet",
    nodes = {
        greet = {
            speaker = "Marchand",
            text    = "Bonjour voyageur ! Que cherches-tu ?",
            next    = "suite",
        },
        suite = {
            speaker = "Marchand",
            text    = "J'ai de belles potions si tu es intéressé.",
            next    = "fin",
        },
        fin = {
            speaker = "Marchand",
            text    = "Reviens quand tu veux !",
            next    = nil,  -- fin de la conversation
        },
    }
})

-- Lancer le dialogue quand le joueur interagit
function OnActivate(activatorId, actionID)
    Conversation.start("marchand_bonjour")
end

lua  ·  Dialogue avec choix et branches
Conversation.define("garde_entree", {
    start = "halte",
    nodes = {
        halte = {
            speaker = "Garde",
            text    = "Halte ! Qui vas-tu ? Que veux-tu ?",
            choices = {
                { text = "Je cherche le roi.",       next = "roi" },
                { text = "Juste passer mon chemin.", next = "passe" },
                { text = "Je t'attaque !",            next = "attaque" },
            }
        },
        roi = {
            speaker = "Garde",
            text    = "Bien. Suivez le couloir à gauche.",
            onEnter = function() Flag.set("garde_parle") end,
            next    = nil,
        },
        passe = {
            speaker = "Garde",
            text    = "Très bien. Ne faites pas d'histoires.",
            next    = nil,
        },
        attaque = {
            speaker = "Garde",
            text    = "Quoi ?! Gardes, à moi !",
            onEnter = function() EventBus.emit("alerte_gardes", {}) end,
            next    = nil,
        },
    }
})

lua  ·  Choix conditionnels (selon flags ou inventaire)
Conversation.define("sage_antique", {
    start = "question",
    nodes = {
        question = {
            speaker = "Sage",
            text    = "Tu es revenu... que veux-tu ?",
            choices = {
                -- Ce choix n'apparaît que si le joueur a la gemme
                {
                    text = "Je t'apporte la Gemme de Feu.",
                    next = "gemme",
                    cond = function() return Inventory.has(joueur.id, "gemme_feu") end,
                },
                -- Ce choix n'apparaît que si le joueur a parlé au roi
                {
                    text = "Le roi m'a parlé de toi.",
                    next = "roi",
                    cond = function() return Flag.get("roi_parle") end,
                },
                { text = "Rien, au revoir.", next = "adieu" },
            }
        },
        gemme = {
            speaker = "Sage",
            text    = "Excellent ! Tu as réussi la quête !",
            onEnter = function() Quest.complete("trouver_gemme") end,
            next    = nil,
        },
        roi  = { speaker = "Sage", text = "Ah oui, Sa Majesté m'a prévenu.", next = nil },
        adieu = { speaker = "Sage", text = "Comme tu veux, voyageur.", next = nil },
    }
})

-- Lancer le dialogue
Conversation.start("sage_antique")
