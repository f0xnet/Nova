Stats

Valeurs numériques par entité — Vie, Attaque, Défense, Mana, Niveau… Équivalent de GetActorValue de Papyrus.

Global automatiqueÉmet des événements

API

FonctionDescriptionRetour
Stats.init(entityId, defaults)Initialise un ensemble de stats depuis une table. N'écrase pas les valeurs déjà définies. N'émet aucun stat_changed — sans bruit pour l'UI au chargement.—
Stats.get(entityId, stat, defaut)Lit la valeur d'une stat. Si absente, retourne defaut.number
Stats.set(entityId, stat, valeur)Définit une stat à une valeur précise. Émet stat_changed et déclenche les bindings réactifs.—
Stats.mod(entityId, stat, delta)Ajoute delta à la stat (négatif = enlever). Retourne la nouvelle valeur.number
Stats.modClamped(entityId, stat, delta, min, max)Comme mod mais borne le résultat entre min et max. Retourne la nouvelle valeur.number
Stats.has(entityId, stat)Vrai si la stat existe.bool
Stats.getAll(entityId)Retourne toutes les stats de l'entité.table
Stats.remove(entityId, stat)Supprime une stat. Si c'était la dernière stat de l'entité, la table interne est libérée.—
Stats.clear(entityId)Supprime toutes les stats de l'entité.—

Bindings réactifs

FonctionDescription
Stats.bind(entityId, stat, fn)Enregistre fn(value, previous, entityId, stat) appelée à chaque Stats.set sur cette stat. Plusieurs bindings par stat sont supportés.
Stats.unbind(entityId, stat, fn)Retire un binding spécifique.
Stats.unbindAll(entityId)Retire tous les bindings de l'entité. Appelé automatiquement lors de entity_destroyed.
Nettoyage automatique : Stats.unbindAll est appelé lors de entity_destroyed — aucune fuite mémoire possible. Pas besoin de cleanup manuel dans OnDeactivate.

Événements émis automatiquement

EventBus

stat_changed{ entityId, stat, value, previous }
stat_zeroed{ entityId, stat }  — quand value ≤ 0

Exemple — Initialisation et combat

lua  ·  scripts/ennemi.lua
function init(entity)
    -- Lire les stats depuis le JSON de scène (self = propriétés JSON)
    Stats.init(entity.id, {
        Vie     = self.vie     or 50,
        VieMax  = self.vie     or 50,
        Attaque = self.attaque or 10,
        Defense = self.defense or 3,
    })
end

-- Recevoir des dégâts
function recevoirDegats(entity, montantBrut)
    local defense     = Stats.get(entity.id, "Defense", 0)
    local degatsReels = math.max(1, montantBrut - defense)  -- minimum 1

    local vie = Stats.mod(entity.id, "Vie", -degatsReels)

    -- Afficher les dégâts
    Notify.floatingText(entity, "-" .. degatsReels, { color = "red" })

    if vie <= 0 then
        mourir(entity)
    end
end

function OnMessage(msg, data)
    if msg == "takeDamage" then
        recevoirDegats(entity, data.amount)
    end
end

Exemple — Réagir automatiquement aux changements

lua  ·  Binding réactif — barre de vie liée à la stat
function init(entity)
    -- Initialiser sans déclencher l'UI (Stats.init est silencieux)
    Stats.init(entity.id, {
        Vie    = self.vie    or 100,
        VieMax = self.vieMax or 100,
    })

    -- Binding : la barre de vie se met à jour à chaque changement de "Vie"
    Stats.bind(entity.id, "Vie", function(value, previous, eid)
        local vieMax = Stats.get(eid, "VieMax", 100)
        UI.setValue("barre_vie", value / vieMax)
    end)
    -- Pas besoin de unbind : nettoyé automatiquement à entity_destroyed
end

lua  ·  Détecter une mort via EventBus
-- Quand n'importe quelle stat "Vie" atteint 0 ou moins
EventBus.on("stat_zeroed", function(data)
    if data.stat == "Vie" then
        local e = Registry:getEntity(data.entityId)
        if e then e:sendMessage("mourir", {}) end
    end
end)
