Game

Accès aux données globales du jeu — joueur, temps, timescale, pause.

Global automatique

API

FonctionDescription
Game.getPlayer()Retourne l'entité avec le tag "player", ou nil.
Game.getTime()Temps de jeu écoulé en secondes (affecté par le timescale).
Game.getDeltaTime()Dernier deltaTime de frame reçu (avant application du timescale).
Game.notification(text)Émet "ui_notification" sur l'EventBus avec le texte fourni.
Game.setTimescale(scale)Multiplie tous les dt. 0.0 = pause, 0.5 = ralenti, 1.0 = normal, 2.0 = accéléré. Émet "timescale_changed".
Game.getTimescale()Valeur courante du timescale.
Game.isPaused()Vrai si le timescale est à 0.0.
Game.pause()Raccourci — appelle Game.setTimescale(0.0).
Game.resume()Raccourci — appelle Game.setTimescale(1.0).
EventBus : Game.setTimescale() émet "timescale_changed" avec { timescale = valeur }. Écoutez cet événement pour mettre à jour l'UI de pause ou les animations.

Exemples

lua  ·  Accéder au joueur depuis n'importe quel script
local joueur = Game.getPlayer()
if joueur then
    local pos = joueur:getPosition()
    Log.info("Joueur à " .. pos.x .. ", " .. pos.y)
else
    Log.warn("Joueur introuvable")
end

lua  ·  Menu pause
-- Dans global.lua ou le script du menu
InputBind.register("pause", "Escape")

EventBus.on("update", function(dt)
    if InputBind.isJustPressed("pause") then
        if Game.isPaused() then
            Game.resume()
            UI.hide("menu_pause")
        else
            Game.pause()
            UI.show("menu_pause")
        end
    end
end)

-- Bouton "Reprendre" dans l'UI
UI.onClick("btn_reprendre", function()
    Game.resume()
    UI.hide("menu_pause")
end)

lua  ·  Bullet time (ralenti temporaire)
function activerBulletTime(duree)
    Game.setTimescale(0.25)
    Sound.playMusic("data/music/slowmo.ogg")

    -- Timer utilise le temps réel (non affecté par le timescale)
    Timer.after(duree, function()
        Game.setTimescale(1.0)
    end)
end

-- Effet visuel en réponse au changement de timescale
EventBus.on("timescale_changed", function(data)
    if data.timescale < 1.0 then
        SceneFX.flash(Color.new(100, 150, 255, 60), 0.3)
    end
end)

lua  ·  Afficher le temps de jeu
function update(entity, dt)
    local t      = Game.getTime()
    local heures = math.floor(t / 3600)
    local mins   = math.floor((t % 3600) / 60)
    local secs   = math.floor(t % 60)

    local label = string.format("%02d:%02d:%02d", heures, mins, secs)
    UI.setText("label_temps", label)
end
