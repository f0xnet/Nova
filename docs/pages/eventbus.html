EventBus

Le système de communication entre scripts. Un script émet un événement, d'autres scripts y réagissent — sans qu'ils se connaissent.

Global automatique
Principe : au lieu qu'un script appelle directement une fonction d'un autre script (ce qui crée des dépendances rigides), il annonce qu'il s'est passé quelque chose. Chaque script intéressé peut réagir.
Nettoyage automatique dans les scripts d'entité et de scène. Tout appel à EventBus.on() ou EventBus.once() effectué dans init() est automatiquement tracké. À la destruction de l'entité (ou au changement de scène pour un script de scène), tous ces handlers sont désinscrits sans action manuelle. Pas besoin de EventBus.off() dans ces contextes.
Ré-entrance sûre. EventBus.emit() travaille sur un snapshot de la liste des handlers avant d'itérer. Un handler peut appeler EventBus.on(), EventBus.off() ou EventBus.emit() sans corrompre la boucle en cours.

API

FonctionDescription
EventBus.on(event, fonction)Écouter un événement en permanence.
EventBus.once(event, fonction)Écouter une seule fois, puis s'arrêter automatiquement.
EventBus.off(event, fonction)Arrêter d'écouter un événement. Passer la même fonction que lors du on().
EventBus.emit(event, data)Émettre un événement. data est une table optionnelle transmise aux listeners.
EventBus.clear(event)Supprimer tous les listeners d'un événement. Sans argument : tout effacer.

Exemple — Communication entre scripts

lua  ·  scripts/ennemi.lua
-- L'ennemi annonce sa mort à tout le monde
function mourir(entity)
    EventBus.emit("ennemi_mort", {
        x    = World.getPosition(entity).x,
        y    = World.getPosition(entity).y,
        type = "goblin",
    })
    entity:disable()
end

lua  ·  scripts/hud.lua
-- Le HUD écoute les morts d'ennemis pour mettre à jour le score
local score = 0

EventBus.on("ennemi_mort", function(data)
    score = score + 10
    Notify.show("+10 points !", { color = "gold", duration = 2 })
end)

lua  ·  scripts/achievement.lua
-- Le système de succès écoute aussi les morts d'ennemis
EventBus.once("ennemi_mort", function(data)
    -- once() : appelé UNE SEULE FOIS puis supprimé automatiquement
    Achievement.unlock("premier_sang")
end)

Exemple — Se désabonner proprement

lua
-- Sauvegarder la référence à la fonction pour pouvoir se désabonner
local function surDegat(data)
    Stats.mod(joueur.id, "Vie", -data.amount)
end

-- S'abonner
EventBus.on("joueur_touche", surDegat)

-- Plus tard, se désabonner (ex: bouclier actif)
EventBus.off("joueur_touche", surDegat)

script_error{ entityId, path, error, phase }
script_error est émis par le moteur dès qu'un script Lua échoue (chargement, init, update, rendu debug, named handler, etc.). phase vaut "load", "init", "update", "render", "wireHandlers", "call", "sendMessage", "reload" ou "reloadAll". entityId vaut 0 pour les scripts globaux et de scène. Pratique pour afficher un overlay d'erreur en dev : 
EventBus.on("script_error", function(d)
    DevConsole.print(string.format("[%s] %s : %s", d.phase, d.path, d.error))
end)
