World

Trouver, déplacer et interagir avec les entités de la scène.

Global automatique
Cache par tag : World.findByTag() et World.findAllByTag() utilisent un cache reconstruit une fois par frame. Appeler ces fonctions 10 fois dans la même frame ne coûte qu'une seule recherche.

API

FonctionDescriptionRetour
World.findByTag(tag)Première entité portant ce tag.entity ou nil
World.findAllByTag(tag)Toutes les entités portant ce tag.table
World.forEach(tag, fonction)Itère les entités avec ce tag. Retourner false dans la fonction pour stopper.—
World.count(tag)Nombre d'entités avec ce tag.number
World.nearest(origine, tag)L'entité la plus proche avec ce tag + la distance.entity, distance
World.distance(a, b)Distance en pixels entre deux entités.number
World.getPosition(entity)Position de l'entité.{x, y}
World.setPosition(entity, x, y)Téléporte l'entité à cette position.—
World.spawn(typeID)Crée une nouvelle entité. Réservé aux cas dynamiques (projectiles).entity
World.destroy(entityId)Détruit définitivement une entité.—
World.raycast(x1,y1,x2,y2,tag)Lance un rayon et retourne le premier objet touché avec ce tag.hit ou nil

Recherche d'entités

lua
-- Trouver LE joueur (tag unique)
local joueur = World.findByTag("player")
if not joueur then return end   -- toujours vérifier !

-- Trouver TOUS les ennemis
local ennemis = World.findAllByTag("enemy")
Notify.show(World.count("enemy") .. " ennemis restants")

-- Trouver l'ennemi le plus proche
local cible, distance = World.nearest(entity, "enemy")
if cible and distance < 200 then
    Nav.moveTo(entity, cible, 100)
end

-- Infliger des dégâts à tous les ennemis proches
World.forEach("enemy", function(ennemi)
    if World.distance(entity, ennemi) < 150 then
        Stats.mod(ennemi.id, "Vie", -10)
    end
    -- retourner false pour arrêter l'itération
end)

Raycast — Ligne de vue

Lance un rayon invisible de A vers B et détecte le premier objet sur la trajectoire.


lua
-- Est-ce qu'un mur bloque la vue entre le PNJ et le joueur ?
local posNPC    = World.getPosition(npc)
local posJoueur = World.getPosition(joueur)

local mur = World.raycast(
    posNPC.x, posNPC.y,      -- départ
    posJoueur.x, posJoueur.y, -- arrivée
    "wall"                    -- tag des objets à tester (optionnel)
)

if not mur then
    -- Aucun mur entre les deux → le PNJ voit le joueur
    attaquer(joueur)
else
    -- Mur à mur.distance pixels
    patrouiller()
end

-- Le résultat contient :
-- hit.entity   = l'entité touchée
-- hit.x, hit.y = le point de contact
-- hit.distance = distance depuis le départ
-- hit.t        = position relative (0..1) sur le rayon
