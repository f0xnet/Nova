i18n

Internationalisation — afficher les textes dans la langue du joueur grâce à des fichiers de traduction.

Global automatique

API

FonctionDescription
i18n.t(cle)Retourne la traduction de la clé dans la langue active. Retourne la clé si non trouvée.
i18n.t(cle, vars)Traduction avec variables. Ex: {nom="Alice", pts=10}.
i18n.setLanguage(code)Change la langue active. Codes : "fr", "en", "de", "es"…
i18n.getLanguage()Code de la langue active.
i18n.available()Liste des codes de langue disponibles.

Fichiers de traduction

Placez vos fichiers dans data/lang/. Un fichier JSON par langue :

json  ·  data/lang/fr.json
{
    "menu.jouer":           "Jouer",
    "menu.options":         "Options",
    "menu.quitter":         "Quitter",
    "hud.vie":              "Vie",
    "notif.niveau":         "Niveau {niveau} atteint !",
    "notif.objet":          "Obtenu : {nom}",
    "dialogue.marchand":    "Bonjour, aventurier !"
}

json  ·  data/lang/en.json
{
    "menu.jouer":           "Play",
    "menu.options":         "Options",
    "menu.quitter":         "Quit",
    "hud.vie":              "HP",
    "notif.niveau":         "Level {niveau} reached!",
    "notif.objet":          "Obtained: {nom}",
    "dialogue.marchand":    "Hello, adventurer!"
}

Exemples

lua  ·  Utiliser les traductions
-- Texte simple
local texte_jouer = i18n.t("menu.jouer")   -- "Jouer" ou "Play"

-- Texte avec variables
local notif = i18n.t("notif.niveau", { niveau = 5 })
Notify.show(notif, "success")  -- "Niveau 5 atteint !"

local objet = i18n.t("notif.objet", { nom = "Épée longue" })
Notify.show(objet)  -- "Obtenu : Épée longue"

-- Dialogue traduit
Conversation.start({
    { speaker = "Marchand", text = i18n.t("dialogue.marchand") }
})

lua  ·  Changer la langue depuis les options
-- Langues disponibles
local langues = i18n.available()   -- { "fr", "en", "de", "es" }

-- Changer la langue
function changerLangue(code)
    i18n.setLanguage(code)
    Persist.set("langue", code)
    Notify.show("Langue : " .. code)
end

-- Restaurer la langue sauvegardée au démarrage
local langue_sauvee = Persist.get("langue", "fr")
i18n.setLanguage(langue_sauvee)
