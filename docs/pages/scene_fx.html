SceneFX

Effets visuels plein écran — fondu au noir, flash de couleur, transitions entre scènes. S'affiche par-dessus tout, UI incluse.

Global automatique

API

FonctionDescription
SceneFX.fadeIn(duree, onFin)Fondu vers le noir (transparent → noir). onFin() appelé quand l'écran est totalement noir.
SceneFX.fadeOut(duree, onFin)Fondu depuis le noir (noir → transparent).
SceneFX.transition(fonction, duree)Fondu in → exécuter fonction() → fondu out. Parfait pour changer de scène.
SceneFX.flash(couleur, duree)Éclat de couleur qui disparaît rapidement. Parfait pour les dégâts, les éclairs.
SceneFX.isActive()Vrai si un effet est en cours.

Exemples

lua  ·  Changer de scène avec fondu
-- La façon recommandée de changer de scène
function allerAuDonjon()
    SceneFX.transition(function()
        -- Cette fonction est appelée quand l'écran est totalement noir
        Scene.setActive("donjon_01")
    end, 0.6)   -- 0.6 seconde pour chaque demi-fondu
end

-- Ou directement via Scene.transition (qui utilise SceneFX en interne)
Scene.transition("donjon_01", { fade = true, duration = 0.5 })

lua  ·  Flash de dégâts
-- Flash rouge quand le joueur est touché
EventBus.on("joueur_touche", function(data)
    SceneFX.flash(Color.new(255, 0, 0, 150), 0.2)
end)

-- Flash blanc à un coup critique
SceneFX.flash(Color.new(255, 255, 255, 200), 0.15)

-- Flash jaune pour un power-up
SceneFX.flash(Color.new(255, 220, 0, 180), 0.3)

lua  ·  Mort du joueur (fondu, respawn, retour)
function joueurMort()
    Sound.play("data/sounds/mort.ogg")

    SceneFX.fadeIn(1.5, function()
        -- Écran totalement noir : réinitialiser
        Stats.set(joueur.id, "Vie", Stats.get(joueur.id, "VieMax", 100))
        World.setPosition(joueur, checkpoint.x, checkpoint.y)
        Sound.playMusic("data/music/theme.ogg")

        -- Retour progressif à l'image
        SceneFX.fadeOut(1.0)
    end)
end
