Log

Écrire des messages dans la console du moteur — informations, avertissements, erreurs et traces de débogage.

Global automatique
Sortie : tous les messages sont préfixés [Lua] et acheminés vers le logger natif du moteur (console et fichier nova.log).

API

FonctionDescription
Log.info(message)Message informatif (blanc). Utiliser pour les événements normaux.
Log.warn(message)Avertissement (jaune). Situation inattendue mais non bloquante.
Log.error(message)Erreur (rouge). Quelque chose s'est mal passé.
Log.debug(message)Trace de débogage (gris). Filtré en production.
Types : message doit être une string. Convertissez avec tostring() avant de passer un nombre, un booléen ou une table.

Exemples

lua  ·  Logs basiques
Log.info("Scène chargée : " .. Scene.current())
Log.warn("Entité introuvable pour le tag 'boss'")
Log.error("Fichier de données manquant : data/items.json")
Log.debug("update — dt=" .. tostring(dt))

lua  ·  Diagnostiquer init
function init(entity)
    Log.info("init — entité id=" .. tostring(entity.id)
             .. " tag=" .. tostring(entity.tag))

    local joueur = World.findByTag("player")
    if joueur == nil then
        Log.warn("Joueur introuvable à l'init (peut-être pas encore chargé)")
    end

    Stats.init(entity.id, { Vie = 100, VieMax = 100 })
    Log.debug("Stats initialisées")
end

lua  ·  Journaliser les erreurs de données
local ok = Data.load("items", "data/items.json")
if not ok then
    Log.error("Impossible de charger data/items.json — les items seront absents")
else
    local count = #Data.getAll("items")
    Log.info("Items chargés : " .. tostring(count))
end

lua  ·  Wrapper utilitaire (optionnel)
-- Préfixer tous les logs d'un script avec son nom
local TAG = "[gobelin] "
local function logI(msg) Log.info(TAG  .. msg) end
local function logW(msg) Log.warn(TAG  .. msg) end
local function logE(msg) Log.error(TAG .. msg) end

function init(entity)
    logI("init id=" .. tostring(entity.id))
end
