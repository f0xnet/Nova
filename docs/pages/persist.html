Persist

Sauvegarde et chargement de données — stocker des valeurs entre les sessions de jeu (scores, progression, options). Versioning et migration automatiques du schéma de sauvegarde.

Global automatique

API

FonctionDescription
Persist.set(clé, valeur)Enregistre une valeur (nombre, texte, booléen, table). Sauvegardé sur disque automatiquement.
Persist.get(clé, défaut)Lit une valeur. Retourne défaut si la clé n'existe pas.
Persist.delete(clé)Supprime une entrée.
Persist.deleteBatch(clés)Supprime plusieurs entrées en une seule écriture sur disque. Préférer à plusieurs appels delete consécutifs.
Persist.getAll()Retourne une copie de toutes les données enregistrées.
Persist.clear()Efface toutes les données sauvegardées.
Persist.save()Force l'écriture sur disque (normalement automatique).
Persist.load()Force le rechargement depuis le disque. Exécute les migrations si nécessaire.

Versioning et migration

FonctionDescription
Persist.setVersion(v)Déclare la version courante du schéma de sauvegarde. À appeler avant Persist.load() (ou au chargement du script global).
Persist.onMigrate(fromV, toV, fn)Enregistre une migration. fn(data) reçoit la table brute, la modifie et la retourne. Appelée automatiquement lors d'un chargement si la version sauvegardée est inférieure à toV.
Fonctionnement : la version du schéma est transparente — elle est écrite dans le fichier de sauvegarde mais jamais exposée via getAll() ou get(). Si le fichier sauvegardé est plus ancien que setVersion(v), les migrations sont appliquées dans l'ordre et le fichier est réécrit automatiquement.
Types supportés : nombres, textes (string), booléens et tables Lua. Les valeurs sont sérialisées automatiquement en Lua lors de la sauvegarde.

Exemples

lua  ·  Sauvegarder et charger la progression
-- Sauvegarder le meilleur score
local score_actuel = 4280
local meilleur     = Persist.get("meilleur_score", 0)

if score_actuel > meilleur then
    Persist.set("meilleur_score", score_actuel)
    Notify.show("Nouveau record : " .. score_actuel .. " !", { color = "lime" })
end

-- Sauvegarder la scène actuelle pour reprendre plus tard
Persist.set("derniere_scene", Scene.current())
Persist.set("joueur_x",      pos.x)
Persist.set("joueur_y",      pos.y)
Persist.set("joueur_vie",    Stats.get(joueur.id, "Vie", 100))

-- Reprendre la partie
local scene = Persist.get("derniere_scene", "ville_principale")
Scene.setActive(scene)

lua  ·  Migration de schéma — renommer une clé
-- Dans votre script global, AVANT le chargement du jeu :

-- v1 : les stats s'appelaient "player_hp" / "player_mp"
-- v2 : renommées en "health" / "mana"

Persist.setVersion(2)

Persist.onMigrate(1, 2, function(data)
    data["health"] = data["player_hp"]
    data["mana"]   = data["player_mp"]
    data["player_hp"] = nil
    data["player_mp"] = nil
    return data
end)

-- Si le fichier sauvegardé est en v1, la migration s'exécute automatiquement.
-- Si la sauvegarde est déjà en v2 (ou absente), rien ne se passe.
Persist.load()

lua  ·  Migration multi-étapes
-- Le jeu est maintenant en v3 ; il a existé en v1 et v2.
Persist.setVersion(3)

-- v1 → v2 : ajout du champ "difficulty" avec valeur par défaut
Persist.onMigrate(1, 2, function(data)
    if not data["difficulty"] then
        data["difficulty"] = "normal"
    end
    return data
end)

-- v2 → v3 : le score était un int, maintenant c'est une table {value, date}
Persist.onMigrate(2, 3, function(data)
    local old = data["meilleur_score"]
    if type(old) == "number" then
        data["meilleur_score"] = { value = old, date = "inconnu" }
    end
    return data
end)

-- Les deux migrations s'enchaînent automatiquement si la sauvegarde est en v1.

lua  ·  Options de jeu persistantes
local volume_musique = Persist.get("option_volume_musique", 0.8)
local volume_sons    = Persist.get("option_volume_sons",    1.0)
Sound.setMusicVolume(volume_musique)
Sound.setVolume(volume_sons)

function changerVolumeMusique(nouvelle_valeur)
    Persist.set("option_volume_musique", nouvelle_valeur)
    Sound.setMusicVolume(nouvelle_valeur)
end
