Scene

Gestion des scènes — charger, changer, recharger. Utilisez toujours SceneFX.transition pour un fondu lors des changements.

Global automatique

Format JSON d'une scène

ChampTypeDescription
namestringNom unique de la scène.
typestring"interior" ou "exterior".
backgroundColor[r, g, b, a]Couleur de fond (0–255).
scriptstringOptionnel. Chemin vers un script Lua chargé automatiquement quand la scène devient active. Déchargé à chaque changement de scène.
entitiesarrayListe des entités de la scène.
pathfindingobjectGraphe de waypoints (optionnel).
json  ·  ma_scene.scene
{
  "name": "Donjon Niveau 1",
  "type": "interior",
  "backgroundColor": [0, 0, 0, 255],
  "script": "data/scripts/donjon_n1_scene.lua",
  "entities": [ ... ]
}

Script de scène

Quand une scène avec un champ script devient active, le moteur charge ce script comme un script global : init() est appelé une fois (sans paramètre), puis update(dt) à chaque frame. Le script est automatiquement déchargé lors du prochain changement de scène.

lua  ·  data/scripts/donjon_n1_scene.lua
-- Script de scène : s'exécute tant que "Donjon Niveau 1" est active
function init()
    Sound.playMusic("data/music/donjon.ogg")
    EventBus.emit("portes_fermer", {})
    Log.info("[donjon_n1] scène active")
end

function update(dt)
    -- Logique propre à la scène (spawns, ambiance…)
end

-- Named handlers disponibles (OnKeyDown, OnTriggerEnter, etc.)
function OnTriggerEnter(triggerId, entityId)
    if triggerId == "exit_zone" then
        Scene.transition("monde_exterieur")
    end
end

API

FonctionDescription
Scene.load(path, nom)Charge une scène depuis un fichier .scene et la met en mémoire sous le nom donné.
Scene.setActive(nom)Active une scène chargée immédiatement (sans fondu). Déclenche le nettoyage de la scène sortante.
Scene.transition(nom, opts)Change de scène avec fondu. Options : opts.fade (bool, défaut true), opts.duration (secondes, défaut 0.5), opts.onBeforeChange (fn appelée pendant le noir).
Scene.current()Nom de la scène actuellement active.
Scene.scope()Alias de current() — pour tagger manuellement des timers/coroutines : Timer.after(1, fn, Scene.scope()).
Scene.listen(event, handler)Équivalent de EventBus.on() mais le handler est automatiquement désinscrit au changement de scène. Préférer à EventBus.on() dans les scripts de scène.
Scene.reload()Re-active la scène courante (utile après une mort ou pour forcer un rechargement).
Scene.has(nom)Vrai si la scène est chargée en mémoire.
Scene.unload(nom)Décharge une scène de la mémoire.
Scene.count()Nombre de scènes actuellement chargées.
Scene.findPath(x1, y1, x2, y2)Pathfinding via le WaypointGraph de la scène active. Retourne une table de {x, y}.

Exemples

lua  ·  Changer de scène avec fondu
-- Méthode recommandée : fondu enchaîné
function entrerDansLeDonjon()
    Scene.transition("donjon_niveau1", {
        fade     = true,
        duration = 0.6,
    })
end

-- onBeforeChange : callback exécuté pendant le noir, avant le changement
-- Idéal pour nettoyer l'UI ou arrêter la musique proprement
function allerVersLaVille()
    Scene.transition("ville_principale", {
        fade     = true,
        duration = 0.5,
        onBeforeChange = function()
            UI.removeUI("hud_donjon")
            Sound.stopMusic()
        end,
    })
end

-- Déclencher depuis un trigger
function OnTriggerEnter(triggerId, entityId)
    local joueur = World.findByTag("player")
    if joueur and entityId == joueur.id then
        entrerDansLeDonjon()
    end
end

lua  ·  Recharger après une mort
function joueurMort()
    SceneFX.fadeIn(1.5, function()
        -- Remettre à zéro les stats
        Stats.set(joueur.id, "Vie", 100)

        -- Revenir au dernier checkpoint
        local cp = World.findByTag("checkpoint_actif")
        if cp then
            World.setPosition(joueur, cp:getPosition().x, cp:getPosition().y)
        else
            -- Pas de checkpoint : recharger la scène entière
            Scene.reload()
        end

        SceneFX.fadeOut(1.0)
    end)
end

lua  ·  Scene.listen — handlers à portée de scène
-- Dans un script de scène : utiliser Scene.listen() plutôt que EventBus.on()
-- Le handler est automatiquement retiré au prochain changement de scène.

-- ❌ Risque de fuite entre scènes
EventBus.on("ennemi_tué", function(data) compterKill(data) end)

-- ✅ Nettoyage automatique
Scene.listen("ennemi_tué", function(data) compterKill(data) end)

-- Jouer une musique différente selon la scène (dans un script global)
Scene.listen("scene_changed", function(data)
    if data.name == "donjon_niveau1" then
        Sound.playMusic("data/music/donjon.ogg")
    elseif data.name == "ville_principale" then
        Sound.playMusic("data/music/ville.ogg")
    end
end)

lua  ·  Pathfinding via WaypointGraph
-- Calcule un chemin entre deux positions (utilise le graphe de la scène active)
local chemin = Scene.findPath(npc:getPosition().x, npc:getPosition().y, 600, 300)

-- Fait suivre le chemin au NPC
Nav.moveAlongPath(npc, chemin, 80, function()
    Log.info("NPC arrivé à destination")
end)
