Math & Vec2

Fonctions mathématiques et vecteurs 2D — interpolation, angles, distances, normalisation.

Global automatique

Math — Utilitaires

FonctionDescription
Math.clamp(valeur, min, max)Limite la valeur entre min et max.
Math.lerp(a, b, t)Interpolation linéaire entre a et b (t entre 0 et 1).
Math.angleTo(x1, y1, x2, y2)Angle en degrés de (x1,y1) vers (x2,y2).
Math.sign(valeur)-1, 0 ou +1 selon le signe.
Math.round(valeur, decimales)Arrondi. decimales optionnel (défaut : 0).
Math.approach(actuel, cible, delta)Avance de delta vers cible sans le dépasser.
Math.map(v, inMin, inMax, outMin, outMax)Convertit une valeur d'un intervalle vers un autre.
Math.smoothstep(edge0, edge1, t)Lissage entre edge0 et edge1.
Math.pingpong(t, longueur)Oscille entre 0 et longueur.
Math.normalizeAngle(deg)Ramène un angle dans [0, 360].
Math.deg2rad(deg)Degrés → radians.
Math.rad2deg(rad)Radians → degrés.

Vec2 — Vecteurs 2D

FonctionDescription
Vec2.new(x, y)Crée un vecteur 2D.
Vec2.length(v)Longueur (magnitude) du vecteur.
Vec2.normalize(v)Vecteur de longueur 1 dans la même direction.
Vec2.distance(a, b)Distance entre deux Vec2.
Vec2.lerp(a, b, t)Interpolation entre deux Vec2.
Vec2.dot(a, b)Produit scalaire.
Vec2.fromAngle(deg, longueur)Vecteur depuis un angle en degrés. Longueur optionnelle (défaut : 1).
Vec2.angle(v)Angle en degrés du vecteur.

lua  ·  Mouvement fluide vers une cible
-- Approcher une valeur de vitesse progressivement (accélération)
local vitesse_actuelle = 0
local vitesse_max      = 200

function OnUpdate(entity, dt)
    -- Math.approach avance de (acceleration * dt) sans dépasser vitesse_max
    vitesse_actuelle = Math.approach(vitesse_actuelle, vitesse_max, 300 * dt)

    local pos = entity:getPosition()
    entity:setPosition(pos.x + vitesse_actuelle * dt, pos.y)
end

lua  ·  Direction et déplacement avec Vec2
-- Calculer la direction normalisée vers une cible
local pos_a = archer:getPosition()
local pos_b = cible:getPosition()

local direction = Vec2.normalize(Vec2.new(
    pos_b.x - pos_a.x,
    pos_b.y - pos_a.y
))

-- Déplacer l'entité dans cette direction
local VITESSE = 150
archer:setPosition(
    pos_a.x + direction.x * VITESSE * dt,
    pos_a.y + direction.y * VITESSE * dt
)
