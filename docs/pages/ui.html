UI

Charger des layouts d'interface, lire et écrire des valeurs, réagir aux clics et actions.

Global automatique
Architecture : les layouts sont définis en JSON dans data/ui/json/. Lua charge les fichiers et se branche sur leurs événements via l'EventBus.

API

FonctionDescription
Chargement
UI.load(path)Charge un fichier JSON de layout. Retourne true si réussi.
UI.removeUI(id)Décharge un layout par son identifiant.
UI.removeGroup(id)Supprime un groupe de composants.
UI.clear()Supprime tous les composants UI.
Visibilité
UI.show(id)Rend un composant visible.
UI.hide(id)Cache un composant.
UI.setVisible(id, bool)Contrôle la visibilité directement.
Lecture / écriture
UI.getText(id)Lit le texte affiché d'un composant Text.
UI.setText(id, texte)Modifie le texte affiché.
UI.getValue(id)Lit la valeur d'un Slider ou TextInput (string ou float).
UI.setValue(id, valeur)Définit la valeur d'un Slider (float) ou Button (string).
Événements
UI.onClick(id, fn)Appelle fn(value, action) quand le composant id déclenche une action.
UI.onAction(action, fn)Appelle fn(value, id) pour une action nommée spécifique.
UI.on(event, fn)Écoute l'événement EventBus "ui_<event>".
UI.off(event)Supprime les écouteurs de "ui_<event>".

Événements reçus

EventBusDonnéesÉmis quand
"ui_action"{ action, value, id }N'importe quel composant déclenche une action
"ui_action_<action>"{ value, id }Action spécifique déclenchée
"ui_click_<id>"{ action, value }Composant spécifique déclenche une action

Callback global (named handler)

Si vous définissez OnUIAction dans un script, il est appelé automatiquement pour chaque action UI.

lua  ·  OnUIAction
function OnUIAction(action, value, id)
    if action == "quit" then
        -- nettoyage avant fermeture
        Persist.set("derniere_scene", Scene.current())
    end
end

Exemples

lua  ·  Menu principal
UI.load("data/ui/json/main_menu.json")

-- Bouton "Jouer"
UI.onClick("btn_jouer", function()
    Scene.transition("monde_01", { fade = true, duration = 1.0 })
end)

-- Bouton "Options"
UI.onClick("btn_options", function()
    UI.hide("panel_menu")
    UI.show("panel_options")
end)

-- Bouton "Quitter"
UI.onClick("btn_quitter", function()
    -- Signal géré par le moteur
    EventBus.emit("quit_requested", {})
end)

lua  ·  Slider de volume
UI.load("data/ui/json/options.json")

-- Initialiser le slider avec la valeur sauvegardée
local vol = Persist.get("option_volume", 0.8)
UI.setValue("slider_volume", vol)

-- Réagir aux changements en temps réel
UI.onClick("slider_volume", function()
    local v = UI.getValue("slider_volume")
    Sound.setVolume(v)
    Persist.set("option_volume", v)
end)

lua  ·  HUD de combat
UI.load("data/ui/json/hud.json")

local joueur = Game.getPlayer()

-- Mettre à jour la barre de vie
EventBus.on("stat_changed", function(data)
    if data.entityId ~= joueur.id then return end
    if data.stat ~= "Vie" then return end

    local pct = data.value / Stats.get(joueur.id, "VieMax", 100)
    UI.setValue("barre_vie", pct)
    UI.setText("label_vie", math.floor(data.value) .. " / "
                            .. math.floor(Stats.get(joueur.id, "VieMax", 100)))
end)

-- Afficher/cacher le HUD selon la scène
EventBus.on("scene_changed", function(d)
    if d.name == "menu_principal" then
        UI.hide("hud_root")
    else
        UI.show("hud_root")
    end
end)

lua  ·  Inventaire ouvert/fermé
local inventaire_ouvert = false

InputBind.register("inventaire", "I")

EventBus.on("update", function(dt)
    if InputBind.isJustPressed("inventaire") then
        inventaire_ouvert = not inventaire_ouvert
        if inventaire_ouvert then
            UI.show("panel_inventaire")
            Game.pause()
        else
            UI.hide("panel_inventaire")
            Game.resume()
        end
    end
end)
