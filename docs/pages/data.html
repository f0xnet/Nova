Data

Charger et interroger des fichiers JSON de configuration — objets, stats, textes. Idéal pour séparer les données du code.

Global automatique

API

FonctionDescription
Data.load(id, chemin)Charge un fichier JSON et l'enregistre sous l'identifiant id. Mis en cache.
Data.reload(id)Recharge le fichier depuis le disque.
Data.isLoaded(id)Vrai si le dataset est chargé.
Data.getAll(id)Retourne toute la table (tableau d'objets ou objet).
Data.get(id, cle)Retourne un élément par sa clé. cle optionnel.
Data.set(id, cle, valeur)Modifie une entrée en mémoire (pas sur le disque).
Data.query(id, fn)Filtre les données : retourne les entrées pour lesquelles fn(entry) est vrai.
Data.unload(id)Libère le dataset de la mémoire.

Exemples

json  ·  data/items.json
[
    { "id": "potion_soin",  "nom": "Potion de soin",  "soin": 30,  "prix": 15 },
    { "id": "epee_longue",  "nom": "Épée longue",     "degats": 25, "prix": 80 },
    { "id": "bouclier_fer", "nom": "Bouclier de fer", "defense": 10, "prix": 60 }
]

lua  ·  Charger et utiliser les données
-- Charger au démarrage du jeu (script global)
Data.load("items", "data/items.json")

-- Récupérer tous les items
local tous_les_items = Data.getAll("items")

-- Chercher un item spécifique avec query
local potions = Data.query("items", function(item)
    return item.soin ~= nil  -- seulement les objets de soin
end)

-- Utiliser les données
for _, potion in ipairs(potions) do
    print(potion.nom .. " soigne " .. potion.soin .. " PV")
end

-- Récupérer directement par clé (si le JSON est un objet, pas un tableau)
local config = Data.get("config", "difficulte")

lua  ·  Sauvegarder une table Lua dans Persist
-- Persist ne stocke que des valeurs simples (nombres, textes, booléens)
-- Pour sauvegarder une table, passez par Resources.loadJSON et Persist

-- Encoder en JSON (via la lib Lua standard ou un helper)
-- Note : utilisez Data.set pour modifier en mémoire, puis Persist pour sauvegarder
-- les valeurs clé par clé

local progression = {
    niveau     = 5,
    experience = 1240,
}

-- Sauvegarder champ par champ
Persist.set("niveau",     progression.niveau)
Persist.set("experience", progression.experience)

-- Recharger
local niveau     = Persist.get("niveau", 1)
local experience = Persist.get("experience", 0)
