Effect

Effets de statut temporaires sur les entités — poison, ralentissement, bouclier, brûlure, invisibilité… Équivalent des ActiveEffects de Papyrus.

Global automatiqueÉmet des événements

API

FonctionDescriptionRetour
Effect.apply(entityId, effectId, config)Applique un effet. Si l'effet existe déjà et n'est pas stackable, renouvelle sa durée.—
Effect.remove(entityId, effectId)Retire un effet immédiatement (déclenche onExpire).—
Effect.has(entityId, effectId)Vrai si l'effet est actif sur cette entité.bool
Effect.clear(entityId)Retire tous les effets de cette entité.—
Effect.getRemaining(entityId, effectId)Secondes restantes pour cet effet.number

Option (config)Description
durationDurée en secondes. -1 = permanent jusqu'à Effect.remove().
stackabletrue = plusieurs instances simultanées possibles (défaut: false).
onApply = function(entityId)Appelée une fois à l'application de l'effet.
onTick = function(entityId, dt)Appelée chaque frame tant que l'effet est actif.
onExpire = function(entityId)Appelée à l'expiration ou lors d'un remove manuel.

Exemples

lua  ·  Poison
Effect.apply(ennemi.id, "poison", {
    duration = 5.0,
    onApply  = function(id)
        Notify.floatingText(Registry:getEntity(id), "☠ Empoisonné", { color = "purple" })
    end,
    onTick   = function(id, dt)
        Stats.mod(id, "Vie", -3 * dt)    -- 3 dégâts par seconde
    end,
    onExpire = function(id)
        Notify.floatingText(Registry:getEntity(id), "Poison dissipé", { color = "gray" })
    end,
})

lua  ·  Bouclier temporaire
-- Bouclier qui dure 10 secondes et absorbe les dégâts
Effect.apply(joueur.id, "bouclier", {
    duration = 10.0,
    onApply  = function(id)
        Stats.set(id, "Armure", Stats.get(id, "Armure", 0) + 30)
        Sound.play("data/sounds/bouclier.ogg")
    end,
    onExpire = function(id)
        Stats.mod(id, "Armure", -30)
        Notify.show("Bouclier dissipé", { color = "blue" })
    end,
})

-- Vérifier si le joueur est protégé
if Effect.has(joueur.id, "bouclier") then
    Notify.show("Bouclier actif !", { color = "blue" })
end

lua  ·  Ralentissement (stackable)
-- Plusieurs ralentissements peuvent s'empiler
Effect.apply(ennemi.id, "ralenti", {
    duration  = 3.0,
    stackable = true,
    onApply   = function(id) Stats.mod(id, "Vitesse", -20) end,
    onExpire  = function(id) Stats.mod(id, "Vitesse",  20) end,
})
