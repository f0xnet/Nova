Math & Vec2

Fonctions mathématiques utiles pour le jeu — distances, angles, interpolation, vecteurs 2D.

Global automatique

Math — Utilitaires

FonctionDescription
Math.clamp(valeur, min, max)Limite la valeur entre min et max.
Math.lerp(a, b, t)Interpolation linéaire entre a et b (t entre 0 et 1).
Math.distance(x1,y1, x2,y2)Distance en pixels entre deux points.
Math.angle(x1,y1, x2,y2)Angle en degrés de (x1,y1) vers (x2,y2). 0=droite, 90=bas.
Math.sign(valeur)-1, 0 ou +1 selon le signe de la valeur.
Math.round(valeur)Arrondi au nombre entier le plus proche.
Math.wrap(valeur, min, max)Boucle la valeur dans l'intervalle [min, max].
Math.degToRad(deg)Degrés → radians.
Math.radToDeg(rad)Radians → degrés.

Vec2 — Vecteurs 2D

FonctionDescription
Vec2.new(x, y)Crée un vecteur 2D.
Vec2.add(a, b)Addition : a + b.
Vec2.sub(a, b)Soustraction : a − b.
Vec2.scale(v, f)Multiplication par un scalaire.
Vec2.length(v)Longueur (magnitude) du vecteur.
Vec2.normalize(v)Vecteur de longueur 1 dans la même direction.
Vec2.dot(a, b)Produit scalaire.
Vec2.fromAngle(deg)Vecteur unitaire depuis un angle en degrés.
Vec2.angle(v)Angle en degrés du vecteur.

lua  ·  Calculs courants
-- Distance entre deux entités
local pos_joueur = World.getPosition(joueur)
local pos_ennemi = World.getPosition(ennemi)
local dist       = Math.distance(pos_joueur.x, pos_joueur.y,
                                  pos_ennemi.x, pos_ennemi.y)

if dist < 100 then
    print("Le joueur est proche !")
end

-- Orienter un projectile vers la souris

local vie = Stats.get(entity.id, "Vie", 100)

lua  ·  Mouvement fluide avec lerp
-- Suivre une cible en douceur (lissage exponentiel)
local pos_actuelle = { x = 0, y = 0 }

function OnUpdate(entity, dt)
    local cible    = World.getPosition(joueur)
    local vitesse  = 5  -- 5 = rapide, 1 = lent

    pos_actuelle.x = Math.lerp(pos_actuelle.x, cible.x, vitesse * dt)
    pos_actuelle.y = Math.lerp(pos_actuelle.y, cible.y, vitesse * dt)

    World.setPosition(entity, pos_actuelle.x, pos_actuelle.y)
end

lua  ·  Direction et déplacement avec Vec2
-- Calculer la direction vers une cible
local pos_a  = World.getPosition(archer)
local pos_b  = World.getPosition(cible)

local direction = Vec2.normalize(Vec2.sub(
    Vec2.new(pos_b.x, pos_b.y),
    Vec2.new(pos_a.x, pos_a.y)
))

-- Déplacer l'entité dans cette direction
local VITESSE = 150
World.setPosition(archer,
    pos_a.x + direction.x * VITESSE * dt,
    pos_a.y + direction.y * VITESSE * dt
)
