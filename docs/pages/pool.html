Pool

Réutiliser des entités plutôt que d'en créer/détruire à chaque instant — essentiel pour les projectiles, effets visuels, ennemis spawns.

Global automatique
Pourquoi un pool ? Créer et détruire des entités est coûteux. Avec un pool, on prépare N entités désactivées au démarrage, puis on les "emprunte" et "rend" sans jamais vraiment créer ou détruire quoi que ce soit.

API

FonctionDescriptionRetour
Pool.create(id, templateFn, taille)Crée un pool. templateFn() doit créer et retourner une entité. Appelée taille fois au démarrage.—
Pool.acquire(id)Emprunte une entité disponible (l'active). Retourne nil si le pool est épuisé.entity ou nil
Pool.release(id, entity)Rend une entité au pool (la désactive).—
Pool.available(id)Nombre d'entités disponibles dans le pool.number
Pool.size(id)Taille totale du pool (actives + disponibles).number
Pool.clear(id)Détruit toutes les entités du pool.—
Pool.clearAll()Détruit tous les pools.—

Exemple — Pool de balles

lua
-- ── INITIALISATION (une seule fois, au début du niveau) ──
Pool.create("balle", function()
    -- Cette fonction est appelée 32 fois pour créer 32 balles
    local e = World.spawn("BulletEntity")
    -- configurer la balle ici (pas de position, elle sera fixée à l'acquire)
    return e
end, 32)  -- pool de 32 balles


-- ── TIRER UNE BALLE ──
function tirer(tireur, angleEnDegres)
    local balle = Pool.acquire("balle")
    if not balle then
        return  -- pool épuisé, ignorer ce tir
    end

    -- Positionner la balle sur le tireur
    local pos = World.getPosition(tireur)
    World.setPosition(balle, pos.x, pos.y)

    -- La vélocité sera gérée par le script de la balle
    balle:sendMessage("init", {
        angle  = angleEnDegres,
        vitesse = 400,
    })

    Sound.play("data/sounds/tir.ogg", 0.6)
end


-- ── RENDRE LA BALLE AU POOL (depuis le script de la balle) ──
function OnMessage(msg, data)
    if msg == "impact" or msg == "expiration" then
        Pool.release("balle", entity)
    end
end


-- ── NETTOYAGE DE FIN DE NIVEAU ──
EventBus.on("scene_changing", function()
    Pool.clear("balle")
end)
